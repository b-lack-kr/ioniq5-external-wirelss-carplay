# 올인원 USB 준비 도구 1.1.3

릴리스에서 `blackr-wireless-carplay-aio-1.1.3-script.zip`을 내려받아 컴퓨터에 압축을 풀고, macOS는 `USB-준비-macOS.command`, Windows는 `Prepare-USB-Windows.cmd`를 실행하세요. Python 설치는 필요 없습니다. 설치 자료와 동글 드라이버는 인터넷으로 받습니다. 자세한 순서는 `먼저읽기.txt`를 참고하세요.

선택한 USB의 기존 파일은 모두 삭제됩니다. 포맷이나 파티션 변경은 하지 않습니다. ADB 개인키는 컴퓨터에 남고 공개키만 설치 USB에 들어갑니다.

1.1.3 안내 수정은 실차 검증 전이며 Windows 준비 도구의 실제 Windows USB 작성은 검증 전입니다. 이 버전은 사전 공개 버전입니다. 출처와 라이선스는 릴리스의 `source-materials.zip`을 확인하세요.
