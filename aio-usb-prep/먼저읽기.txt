아이오닉 5 무선 CarPlay 올인원 1.1.3 USB 준비

대상: 아이오닉 5 한국형 NEEV 260902, 외장 5GHz USB Wi-Fi 동글.
차량에 NEMESIS와 HMG-API 1.0.2 이상이 설치되어 있어야 합니다.
Python을 따로 설치할 필요는 없습니다. 인터넷 연결이 필요합니다.

1. 이 압축파일을 컴퓨터의 폴더에 풉니다.
2. Mac은 USB-준비-macOS.command, Windows는 Prepare-USB-Windows.cmd를 실행합니다.
3. 표시된 USB를 선택하고 확인 문구를 입력합니다. 선택한 USB 안의 기존 파일은 모두 삭제되므로 필요한 파일은 미리 백업하세요. USB를 포맷하거나 파티션을 변경하지 않습니다.
4. 프로그램은 GitHub 설치 자료와 GRT47 원본 드라이버를 내려받고 해시를 확인합니다. ADB 키가 없으면 Google 공식 도구를 받아 이 컴퓨터의 키를 만듭니다. USB에는 공개키만 포함합니다.
5. 차량에서 기존 CarPlay, 동글 ADB, WARMER, 음소거, 프리컨디셔닝 관련 패키지와 HMG-API 모드를 삭제합니다. HMG-API에서 Apply changes 후 내비를 재부팅합니다.
6. 차량과 아이폰에서 기존 Bluetooth 기기를 지우고, 아이폰 설정 > 일반 > CarPlay에서도 기존 차량을 지웁니다.
7. USB를 차량에 꽂고 설치한 뒤 동글을 연결하고 내비를 재부팅합니다. Bluetooth를 새로 연결하고 CarPlay 연결을 승인합니다.
8. 연결 알림이 없으면 아이폰 Bluetooth를 껐다 켜고 차량 기기 연결 화면에서 다시 연결합니다. 그래도 안 되면 내비를 재부팅하고 다시 시도합니다.

CarPlay 1.1.3의 안내 수정 및 이 Windows 준비 도구는 각각 실차와 실제 Windows 환경에서 검증 전입니다. 차량 환경에 따라 설치 및 동작이 달라질 수 있습니다.
프리컨디셔닝 즐겨찾기는 확인된 차종·펌웨어에서만 사용하세요.
