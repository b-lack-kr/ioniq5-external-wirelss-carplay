NEEV.KOR.260902 CarPlay TBT 매핑 검토표 (2026-11-05)
기준: 오른쪽 통행, 보통 교차로, 선택 각도 없음, 안내 중 상태. 0번 NoTurn은 53개 동작 유형과 별도로 표시.
기본 아이콘 있는 유형 47개. 이 중 회전교차로21개는 각도가 없으면 일반 아이콘64와 안내 문구를 사용.
51번은 선택 각도가 있을 때 추가 지원. 10/11/16/17/27은 확인되지 않은 아이콘을 임의로 대입하지 않음.
이 표는 코드 송신값이며 실제 계기판/HUD 그림 및 강조 표시까지 실차 검증됐다는 뜻은 아님.

이번 확장
- OffRamp8: 측면 미상86 / 왼쪽82 / 오른쪽81.
- OnRamp9: 측면 미상172 / 왼쪽174 / 오른쪽173.
- ChangeHighway51: 선택 각도 음수174 / 양수173. 각도 없음·0·±180이면 추측하지 않음.
- 22/23/52/53: 유형 자체가 좌/우를 지정하므로 선택 각도가 0이 아니어도 표시.
- 기존 한국차 범위(side0/intersection)를 유지. 통행 방향을 출구 좌우로 오해하거나 반전하지 않음.

터널
- CarPlay ManeuverType에 터널 항목이 없는 사실은 순정 계기판에 터널 그림이 없다는 뜻이 아님.
- 현재 확보 자료에서 터널의 OEM 번호는 확인되지 않음. 명확한 터널 안내 문장은 보존하지만 번호를 추측하지 않음.
- 참고 Navi APK는 TBT 표시값을 그대로 NavigationCluster에 넘김. 실제 생성은 ExSLNavi/ExSLAndroidJNI 네이티브 라이브러리에 있음.
- 공개 commaai/opendbc 현대2015mcan DBC에 TBT_Display_Type8bit 필드는 있으나 값별 아이콘 목록(VAL_) 없음. 다른차종/HDA색상 NAV_ICON 값을 TBT로 가져오지 않음.

근거 범위
- Apple SDK CPManeuver.h 0~53 enum을 모두 대조. latest HMG-API/main CpTurns도 기존 제한된 표이며 터널 번호가 추가되지 않았음.
- 새램프 근거: 참고 GPM.setRampDisplayType. NEMESIS의 stockGPM ODEX hash96cd7c27a9db19acb3900f21f57ea9f0은 EV6 USA260507/CAN260206 자료와 일치.
- 한국 NEEV260902의 GPM ODEX hashc38a7fd61f90973625401501215375db와 동일하지 않음. 신규86 등은 실차 확인 필요.
- 기계판독용 전체조건/해시/자료파일명: TBT_MAPPING_AUDIT.json.
- 공개 DBC 출처 고정기록: tbt-research/PUBLIC_SOURCES.json (root 조사).
