1.0.7 적용 안내
이 영역은 기존 1.0.6 동작을 유지합니다. 최신 변경 범위는 CHANGELOG-1.0.7-KO.txt를 확인하세요.

CarPlay 1.0.7 — 상시 기록과 USB 수집

USB 없이 차량 내부 development-log 서비스가 기록합니다. 현재 파일과 이전 3개 파일을
각 2MiB, 합계 8MiB로 순환 보관하며 여유 공간 64MiB 미만에서는 새 기록을 건너뜁니다.
전원 손실·순환 덮어쓰기·행 길이 제한 때문에 모든 과거 기록이 보장되지는 않습니다.

이번에 보존하는 기록
- USB_CP_VIDEO rebind_ready/request/result: 재부착 정책, 세대·시간, hide/show 반환과 예외 상태.
- 기존 화면 timeout/stop/start, 화면·Surface·소유권 및 세션 이벤트.
- USB_CP_TBT_RENDER: 실제 tbtInfo 호출 후 거리 출처, 거리, 유형, 각도, 진행 단계·단위·유효성.
  초당 최대 한 번이며 변화된 출력만 표본 기록합니다. 거리의 Milli는 숫자에 1000을 곱한 값입니다.
  metersMilli는 미터 환산값×1000이고 distanceMilli는 unit으로 표시하는 거리값×1000입니다.
  source=display는 반올림된 표시 거리 기반임을 뜻합니다. 실제 차량 좌표/궤적은 기록하지 않습니다.
- USB 인식 reason/method/모델 VID:PID, provider/observer의 고정 실패 분류 및 상태·횟수.
- 기존 오디오·차속/GPS 입력·전송 집계, 전원 OFF/ON, 순정 TBT 표본 및 USB 전원 속성.

재부착 성공 반환은 영상이 실제 갱신된다는 증거가 아닙니다. 실제 화면 복구와 이후 이벤트를
함께 확인합니다. 정상 앱 전환을 주기적 화면 복구로 오해하지 않도록 신호·소유권을 제한했습니다.

가져오는 순서
1. 설치 완료 후 동글을 꽂고 재부팅하여 평소처럼 사용합니다.
2. 화면 정지가 보이면 시각과 복구 여부를 기억해 두세요. 정차 후 기록해도 됩니다.
3. 패키지를 삭제하기 전에 동글을 빼고 같은 설치 USB를 꽂아 Yes를 누릅니다.
4. 같은 1.0.7의 정상 설치가 확인되면 재설치 없이 기록만 저장합니다. 완료 후 Mac으로 가져옵니다.

NEEV_BUNDLE_RESULT_...에는 기록·수집 상태, USB_AUTO_RESULT_...에는 자동 분류 결과가 남습니다.
실시간 logcat 수집만 TIMEOUT인 경우 저장된 development/persistent 파일이 남을 수 있습니다.
수집 결과는 상태 파일과 함께 확인합니다. 미설치·지원 이전 버전이면 USB는 설치/업데이트를 하므로
시험 후 로그를 받을 때 패키지를 먼저 삭제하지 마세요. USB 내용 교체는 필요 없습니다.

내보내기는 허용된 이벤트·숫자·모델 ID만 재구성합니다. 도로명·GPS 좌표·SSID·암호·휴대전화
식별자·일련번호·파일 경로는 복사하지 않습니다. 일반 수집은 펌웨어 코드 파일을 가져오지 않습니다.

1.0.7 추가: USB_CP_TBT_PROGRESS 로그는 CP의main/fine입력과순정native진행값을 숫자로만 기록합니다.
순정내비의 native_progress는단일bar값만1Hz이하로기록하며 경고필드·위치·도로명은내보내지않습니다.
Fine submitted는API호출제출기록이며실제계기판렌더링성공확인은아닙니다.
