IONIQ 5 USB CarPlay 1.0.5 — 반영 범위
by blackr / 2026-11-06 / 소스 검증과 실차 성공은 구별합니다.

기본 구성
기존 동글/AP, 연결 브리지, 정상 확인된 안내 음량 처리 및 1.0.4의 차선·TBT,
순정 기기 목록 연결, 전원 OFF/ON 처리, 상시 로그를 유지합니다.
전체 upstream PR 검토 이력은 FEATURE-COVERAGE-1.0.4-KO.txt에 남아 있습니다.
새 버전이 HMG-API의 모든 독립 기능을 설치하거나 모든 AR 표시를 보장하는 것은 아닙니다.

이번 구현
차속: 요청된 무선 세션의 실제 MICOM 콜백 기반 PASCD 추가 전달, 최대 추가 4Hz.
TBT: 유효한 ±360° 선택 각도의 정규화, 전체 정의 유형의 지원 범위 명시.
화면: 성공한 Surface 재부착 후 한 번 새 키프레임 요청, 종료·숨김·교체 시 취소.
자료: 순정 TBT 숫자 프레임, USB 동글 전원 속성의 제한된 읽기 전용 기록.
설치: 알려진 1.0.4에서의 업데이트/삭제 후 설치, 같은 1.0.5 USB 자동 로그 수집.

확인되지 않은 범위
GPS 좌표는 기존에도 콜백 즉시 전달됩니다. 아이폰 센서 융합 및 앱 표시까지의 전체 지연은
이번 코드 수정만으로 해결했다고 볼 수 없습니다. 터널 전용 OEM 타입 번호, 모든 sideStreet/
AR HUD 표현, 오류 신호가 없는 화면 정지 자동 감지는 확인 자료가 부족합니다.
USB 5V 차단은 포트별 제어 및 복구 경로가 미확인이므로 넣지 않았습니다.
화면·센서·HUD 실제 동작은 다음 차량 시험에서 확인합니다.
