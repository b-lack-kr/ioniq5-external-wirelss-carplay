# 1.0.3 설치 변경사항

- 새로 설치하거나 NEMESIS에서 기존 CarPlay 패키지를 삭제한 뒤 설치할 수 있습니다.
- 설치된 1.0.3과 같은 USB를 다시 꽂으면 재설치하지 않고 기록을 수집합니다.
- 1.0.2가 설치되어 있으면 NEMESIS에서 삭제한 뒤 설치하도록 안내합니다. 삭제 후 남은 설치 기록은 검증하여 보관하고 새 설치를 진행합니다.
- 음소거·일시정지 패키지는 별도 설치입니다. 다른 패키지를 삭제하지 않습니다.
- NEMESIS와 HMG-API 설치 상태를 확인하며, HMG-API는 1.0.1 이상을 지원합니다. 서명 및 해당 차량 펌웨어 검증도 유지합니다.

## 설치 순서

1. 기존 CarPlay 패키지가 있다면 NEMESIS에서 삭제합니다.
2. 준비한 1.0.3 USB를 차량에 연결하고 실행 확인 창에서 Yes를 선택합니다.
3. 설치 완료를 확인한 뒤 USB를 동글로 교체하고 내비를 재부팅합니다.
4. 차량과 아이폰에 남은 이전 Bluetooth·CarPlay 등록을 지운 뒤 새로 연결합니다.
5. 시험 후 같은 USB를 차량에 다시 연결하고 Yes를 선택하면 기록이 저장됩니다.

설치가 중단되면 USB 기록을 확인합니다. 아직 적용되지 않은 다른 HMG-API 변경이 있는 경우 설치기가 임의로 적용하지 않습니다.
