1.0.13 — 정상 동작했던 1.0.9 CarPlay TBT 경로 복원
2026-11-08 / by blackr

복원 기준
사용자가 마지막 정상 버전을 1.0.9로 확인했습니다. 1.0.9와 이후 Seogaemo 적용판을 비교하고, CarPlay TBT의 입력·해석·출력을 1.0.9 방식으로 복원합니다. 원인이 확정된 특정 버그 하나를 고쳤다는 의미가 아니라 회귀 가능 범위를 제거하는 복원본입니다.

비교에서 확인한 사실
- 1.0.9~1.0.12의 차량 API 매핑 7개와 CarPlay native 패치 4개는 동일합니다.
- iAP2 리스너 등록과 안내 메시지 120/121/122 수신 경로는 동일합니다.
- 1.0.10부터 무선 입력 경로에 원시 차선 파서와 차선 기반 정션 그림 선택, AR 막대 추가 전송이 들어갔습니다.
- 1.0.11부터 주기적 TBT/HUD/차선 재전송, 별도 차선 거리 송신, 차선 색상 합성 및 로딩/재탐색 표시 방식이 바뀌었습니다.
- 합성 안내 입력 비교에서는 기존 버전들의 일반 회전 출력 자체가 모두 나왔습니다. 이것은 실제 차량 Binder 처리·화면 표시를 재현한 결과가 아닙니다. TBT 소실 원인으로 특정 변경을 확정하지 않았습니다.

되돌린 부분
- CarPlay 무선 iAP2 입력에서 추가 원시 차선 파서를 실행하지 않습니다. 1.0.9의 통신 전달 경로를 복원합니다.
- CarPlay 기본 턴·거리·남은 거리·HUD 목록·차선 변환을 1.0.9 방식으로 복원합니다.
- 1.0.11에서 추가한 1초/2초 주기 화면 재전송과 별도 차선 거리 API 호출을 제거합니다. 실제 안내 데이터 변화에 따라 갱신하던 방식으로 돌아갑니다. 기존 남은 거리 중복 억제는 유지합니다.
- 새 로딩/재탐색 상태 화면 전환과 Seogaemo 차선 기반 PE14 그림 선택을 실행 경로에서 제외합니다.
- 추천 차선 자체는 1.0.9의 휴대폰 강조 방향 기반 매핑으로 유지합니다. 1.0.11의 새 3방향 색상 합성까지 유지했다고 표시하지 않습니다.
- 정션뷰는 1.0.9의 명시적인 교차로 각도 기반 선택만 유지합니다. Seogaemo의 차선 기반 그림 선택 범위는 이번 복원본에 적용하지 않습니다.

유지한 개선
- 1.0.12의 차속 즉시 송신·같은 차속 중복 억제·세션 교체 검사, 순정 전원/문 상태 감지와 AP 종료 처리.
- 기존 음악/내비 음량 처리, 5GHz 외부 동글 연결, 개발 로그, 독립 음소거 패키지.
- 공개 설정은 AR 턴 표시(기본 OFF, CP/AA 공통)와 외부 USB Wi-Fi 동글 사용(기본 ON) 두 개입니다.
- AR OFF에서도 기본 TBT·추천 차선·지원되는 각도 기반 정션 그림은 유지합니다. 이전 숨겨진 OFF 설정이 기본 기능을 막지 않습니다.
- CarPlay AR을 켜면 1.0.9의 457m 근사 정책으로 동작합니다. 순정과 같은 접근/통과 애니메이션을 구현했다는 뜻이 아닙니다. Android Auto는 1.0.12의 50m/600m 정책과 독립 앱 파트 도우미를 유지합니다. 스위치만 공통이며 두 구현의 전환 거리는 다릅니다.

설치와 확인
- 인증된 1.0.11/1.0.12 설치본에서 업데이트할 수 있고, NEMESIS Uninstall 후 신규 설치도 지원합니다. 이전 복구 기록을 보존합니다.
- 설치 완료 후 동글을 꽂고 내비를 재부팅합니다. 같은 1.0.13 USB를 다시 꽂고 Yes를 누르면 재설치하지 않고 로그를 수집합니다.
- 차량에는 아직 적용하지 않았습니다. 실제 TBT 복구 및 화면 멈춤 감소는 실차 확인이 필요합니다. USB의 물리 5V 차단이나 0m 회전 통과 커서 애니메이션은 해결 완료 항목이 아닙니다.

대응 소스와 출처
HMG-API·Leafia 참조 및 기존 AGPL 표기를 유지합니다. Android Auto 등 유지된 Seogaemo 파생 코드와 참조용 도우미의 원저작자·라이선스도 보존합니다. 실행 경로에서 제외한 CarPlay 확장 코드가 소스에 남아 있어도 활성 기능으로 주장하지 않습니다.
