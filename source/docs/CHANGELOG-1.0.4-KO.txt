CarPlay 1.0.4 — by blackr
기준일2026-11-06 / 한국 NEEV 260902

USB 자동 실행 개정(같은 1.0.4 본체)
- USB 실행 Yes 후 같은 버전이 정상 설치되어 있으면 로그만 수집합니다.
- 미설치·지원하는 이전 버전은 NEMESIS를 통해 CarPlay를 설치/업데이트합니다.
- 서명된 CarPlay 본체·설치 트랜잭션·기존 수집기·네이티브 패키지는 바이트 그대로 유지합니다.
- 시작 동의4.3.2와 음소거는 독립 패키지이며 자동으로 설치·검사하지 않습니다.
- Uninstall 적용 및 재부팅은 이 패키지의 변경을 해제합니다. HMG-API/NEMESIS 및
  다른 패키지, 설정·백업·로그까지 지우는 차량 공장 초기화는 아닙니다.

1. CarPlay 차선·계기판·HUD
- 휴대전화 안내 중 순정 내비 차선 정보의 덮어쓰기를 막았습니다.
- 추천 방향을 차선 전체가 아니라 화살표별로 표현하도록 수정했습니다.
- 먼저 도착한 차선 정보를 보관하고 현재 회전 안내 번호와 연결합니다.
- 확인된 회전·유턴·진출·회전교차로를 순정 형식과 거리 막대로 보냅니다.
  ‘CarPlay 순정 형식 턴 표시’ 기본 켜짐이며 끄면 기존 아이콘 형식으로 돌아갑니다.
- 표시 여부·색·AR 애니메이션은 실차 확인 전입니다. 터널 전용 아이콘의 전체 매핑은
  완료하지 않았으며 휴대전화 안내 문구 보존을 유지합니다.

2. Android Auto
- 계기판·HUD 안내와 USB 메모리·허브를 휴대전화로 오인하는 경로를 추가 보완합니다.
- 순정 형식 턴 표시는 별도 옵션이며 기본 꺼짐입니다.
- 새 외부 동글 AA 연결 어댑터는 별도 검증 소스로 보관하고 이번 설치본에서 제외했습니다.
  추가 연결 맵의 실제 차량 해석을 확인한 후 별도 적용할 수 있습니다.

3. 전원과 기존 동글 유지
- 실제 순정 CarPlay 앱의 논리 전원 OFF/ON 콜백으로 AP 종료·복귀를 처리합니다.
- 일반 전원 조회가 종료 결정을 곧바로 덮어쓰지 못하도록 했습니다.
- 기존 드라이버·5GHz AP·SSID·암호·연결 정보를 유지합니다.
- 외부 USB Wi-Fi 동글 사용 ON/OFF 설정을 추가했습니다. 기본 ON이며 적용 후
  내비를 재부팅합니다. OFF는 이 패키지의 AP를 사용하지 않는다는 뜻입니다.
- 굿바이 영상 파일 교체나 USB5V 전원 차단 기능은 아닙니다.

4. 화면 멈춤 기록·재요청
- USB 없이 개발 로그를 총8MiB 순환 저장하고 나중에 USB로 내보냅니다.
- 화면 수명·오류·세션·전원·오디오·위치 전송 기록을 남깁니다.
- 활성 무선 세션의 특정 디코더 오류·타임아웃에서만 키 프레임을 다시 요청합니다.
  최소2초 간격, 한 번에 하나만 실행하며 주기적 강제 재연결은 하지 않습니다.
- 모든 화면 멈춤의 원인과 복구를 확인한 것은 아닙니다.

5. 순정 설정 버튼
- 홈 폰 프로젝션 팝업과 무선 설정 메뉴에서 기존 페어링 기기 목록을 엽니다.
- 사용자가 목록에서 삭제하면 Bluetooth 연결 정보도 같이 삭제됩니다.
- 설정 검색·유선 설정 경로는 유지합니다. 자동으로 휴대전화를 삭제하지 않습니다.

6. 설치·유지 사항
- 인증된1.0.3에서 삭제 없이 업데이트하며 실패 시 이전 설치로 복구합니다.
- 기존 신규 설치와1.0.1·1.0.2 업데이트 경로를 유지합니다.
- 사용자가 성공을 확인한1.0.3 안내 음량 처리를 변경하지 않았습니다.
- HMG-API는1.0.1 이상이며 설치된1.0.2를 그대로 사용합니다.
- 시작 동의 자동 처리4.3.2는 별도 패키지로 제공하며 두 항목은 독립 설치합니다.
- 음소거 패키지를 대신 설치하거나 그 설치 여부를 검사하지 않습니다.
