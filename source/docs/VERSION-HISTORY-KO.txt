IONIQ 5 USB 무선 CarPlay — 버전별 변경 이력
by blackr
정리 기준: 2026-11-06, 한국 NEEV 260902용 프로젝트 기록

이 문서는 각 버전에 추가된 기능과 실제 확인 결과를 구분해 정리합니다.
개별 버전의 설치 안내는 그 버전의 사용안내와 변경사항을 따르세요.
아래 1.0.7 설명은 당시 기록입니다. 현재 준비 버전은 1.0.15입니다. 1.0.6을 설치하지 않아도1.0.5에서 직접 업데이트할 수 있습니다. 1.0.5에서는 신규 설치 성공과 화면 timeout→stop 두 번이 확인됐고, 1.0.6 자동 복구의 실차 결과는 확인 전입니다.

1.0.0 — 정식 패키지 구성으로 전환
- 지원되는 5 GHz USB Wi-Fi 동글을 사용하는 무선 CarPlay를 정식 이름과 by blackr 표기로 구성했습니다.
- 신규 설치와 지원되는 이전 개발 버전의 업데이트·복구 경로를 마련했습니다.
- 신규 설치 시 Hyundai_와 숫자 6자리로 Wi-Fi 이름을 생성하고, 지원되는 업데이트에서는 기존 연결 설정을 유지합니다.
- 계기판·HUD로 회전·거리 안내를 전달하며, 유턴·회전교차로·몇 시 방향 변환과 앱이 보내는 차선 정보의 전달 경로를 포함했습니다.
- 정상 부팅, 동글 시작, CarPlay 연결 대기 팝업을 제거했습니다. 설치 결과와 실행 실패 알림은 유지했습니다.
- 당시 배포 구성에는 음소거 시 CarPlay 음악에 일시정지를 요청하는 별도 음소거 패키지가 함께 포함됐습니다.
확인 결과: 신규 설치 후 동글 자동 시작과 설치 완료 검증에 문제가 보고되어 1.0.1에서 수정했습니다.

1.0.1 — 신규 설치와 동글 자동 시작 수정
- Android 준비 완료 전에 동글 드라이버를 먼저 로드하도록 부팅 순서를 수정했습니다.
- 사용하는 임시 파일만 검사하여 무관한 보조 링크가 실행을 막지 않도록 했습니다.
- 자동 시작 서비스 등록을 확인하고, 기존 패키지를 삭제한 뒤 남은 작업 폴더를 보관해 새로 설치할 수 있도록 했습니다.
- Mac의 ._LICENSE 같은 보조 파일 때문에 설치 결과가 Operation failed로 끝나던 검증 경로를 수정했습니다.
- 당시 통합 배포 구성의 음소거 패키지를 1.1.0으로 올렸습니다. 음소거로 멈춘 음악은 음소거 해제 또는 볼륨 조절로 소리가 다시 켜지면 재생합니다. 원래 일시정지된 곡은 유지합니다.
확인 결과: 사용자가 대상 아이오닉 5에서 기존 패키지 삭제 후 설치와 기본 동작이 정상임을 확인했습니다.

1.0.1 유지 중 수정한 PC 준비 도구
- USB 파티션 생성·포맷을 제거하고, 선택한 볼륨의 기존 파일을 지운 뒤 설치 파일을 복사하도록 바꿨습니다.
- Mac USB 목록 인식과 AppleDouble(._) 파일 처리, Windows 임시 폴더 경로 생성 문제를 수정했습니다.
- Mac의 실제 USB 복사와 해시·볼륨 유지, Windows PowerShell 및 가상 디스크 검사를 수행했습니다. Windows 물리 USB 실사용 검증과는 구분합니다.
- 이 변경들은 PC 준비 도구에 적용했으며 차량용 CarPlay 버전은 1.0.1을 유지했습니다.

1.0.2 — 차선·안내 변환 보강과 호환성·기록 개선
- HMG-API 1.0.1 이상을 사용하도록 설치 조건을 정리하여 기존 HMG-API 1.0.2에서도 설치할 수 있게 했습니다.
- 1.0.1에서 연결 설정을 유지하는 업데이트와 실패 시 복구를 추가했습니다. HMG-API 업데이트로 대상 차량의 훅 맵이 사라진 경우를 처리했습니다.
- CarPlay와 음소거 패키지를 각각 설치하는 구성으로 분리했습니다. CarPlay가 음소거 패키지를 대신 설치하거나 그 버전을 검사하지 않습니다.
- 추천 차선 각도 처리와 중복 화살표를 보강하고, 차선 목록이 없는 메시지로 기존 표시가 지워지는 것을 줄였습니다.
- 같은 방향을 반복하는 안내 문구를 줄이고 진입로·진출로·고속도로 분기 등의 변환을 확대했습니다.
- 터널 문구를 보존하도록 했습니다. 순정 터널 전용 아이콘 번호는 확정하지 않았습니다.
- 순정 전원 상태를 조회해 AP를 멈추고 다시 켜는 처리를 처음 추가했습니다. 이후 대상 차량에서 종료 시 연결이 유지되는 문제가 확인되어 1.0.4에서 전원 이벤트 방식으로 보강합니다.
- 안내 시작 신호와 오디오 채널 시작 순서를 보정하고, 실패한 음악 채널 요청이 성공으로 남는 경우를 수정했습니다.
- GPS·차속 전달 간격, 안내 오디오 채널과 음량 키 상태를 기록하도록 했습니다. 위치·차속 지연 자체를 해결한 버전은 아닙니다.
- USB 기록 수집과 설치 이력을 보강했습니다. 당시 일반 수집에는 고정된 순정 코드 파일 수집도 포함돼 있었습니다.
확인 결과: 설치와 음악 음량은 동작했으나 실제 길안내 음성의 음량 문제는 남아 1.0.3에서 추가 수정했습니다. 차선·터널 등 모든 안내 유형의 실차 표시를 확인한 상태는 아닙니다.

1.0.3 — 실제 길안내 음량 처리 수정
- 무선 CarPlay의 안내용 Alt 보조 오디오를 처음부터 차량 내비게이션 음량 채널로 연결합니다.
- 안내 중 duck/unduck 신호에 따라 보조 오디오 채널을 다시 바꾸던 동작을 제거했습니다.
- 음악·통화·Siri·유선 CarPlay와 기존 TBT 처리를 유지했습니다. 같은 보조 채널로 들어오는 일부 알림음도 내비 음량을 따를 수 있습니다.
- 인증된 기존 1.0.2에서 삭제 없이 업데이트하고, 실패하면 이전 설치로 복구할 수 있도록 했습니다.
- 같은 USB에 제공된 시작 동의 자동 처리 4.3.2는 CarPlay와 각각 설치·삭제하는 독립 패키지입니다. 이 패키지의 코드·버전은 변경하지 않았습니다.
확인 결과: 사용자가 1.0.3에서 내비 안내 음량 조절이 해결됐다고 확인했습니다. 종료 후 CarPlay 연결 유지와 간헐적인 화면 멈춤 문제는 별도 작업으로 이어졌습니다.

1.0.4 — 전원·기록·화면 복구 요청·TBT 표시 개선
구현된 내용
- USB 자동 실행 개정: 실행 Yes 후 같은 1.0.4의 정상 설치가 확인되면 로그만 수집합니다. 미설치·지원하는 이전 버전은 NEMESIS로 설치/업데이트하고, 손상된 같은 버전이나 알 수 없는 버전은 중단합니다. 기존 1.0.4 본체·수집기·네이티브 패키지는 바꾸지 않았습니다.
- 실제 순정 CarPlay 앱의 전원 OFF/ON 콜백을 관찰해 외부 AP를 중지·복귀시킵니다. 일반 전원 조회가 ON으로 남아도 명시적인 OFF 결정을 덮어쓰지 않습니다.
- 같은 부팅 중 서비스 재시작이나 늦게 전달된 이전 이벤트로 AP가 다시 켜지는 것을 막고, 명시적인 복귀 이벤트에서 기존 SSID·암호·연결 설정을 유지해 재시작합니다.
- 동글용 AP·DHCP와 검증된 해당 네트워크 인터페이스만 제어합니다. USB 5V를 차단하거나 굿바이 애니메이션 자체를 후킹하는 기능은 아닙니다.
- ‘외부 USB Wi-Fi 동글 사용’ 설정을 추가했습니다. 기본값은 켜짐이며 기존 드라이버·AP 방식을 유지합니다. 끄면 이 패키지의 외부 AP를 시작하지 않습니다. 설정 적용 후 서비스 또는 내비 재시작이 필요하며, 내장 Wi-Fi가 없는 차량에서는 무선 연결을 사용할 수 없습니다.
- 별도 GRT 패키지의 실행 중인 AP를 가져오는 방식으로 변경하지 않았습니다. 기존 의존 파일 가져오기와 동글 준비 방식은 유지합니다.
- USB 없이 차량 내부에 개발 로그를 계속 저장합니다. 원본은 비공개 권한으로 최대 2MiB 파일 4개를 순환 보관하고, 여유 공간 64MiB 미만에서는 새 쓰기를 건너뜁니다.
- 화면 표시·디코더·Surface 생명주기와 주기별 상태를 기록하고, 프로세스 PID·시간·기록기 시작 표식을 보존합니다.
- 활성 무선 CarPlay 세션에서 확인된 디코더 오류·화면 시간 초과 이벤트가 오면 새 기준 화면을 요청합니다. 요청은 한 번에 하나만 처리하고 최소 간격을 두며, 주기적인 강제 요청이나 앱 재시작은 하지 않습니다. 요청 성공이 실제 화면 복구 성공을 뜻하지는 않습니다.
- USB에서는 저장된 네 파일의 허용된 상태·수치만 추출합니다. 일반 기록 수집에서 순정 코드 파일 수집을 분리해 별도 명령으로 옮겼습니다.
- 홈의 폰 프로젝션 팝업 ‘설정’과 Bluetooth 설정의 무선 폰 프로젝션 메뉴를, USB 브리지가 실제 사용하는 순정 기기 연결 목록으로 연결합니다. NEMESIS 실행 버튼은 기존 HMG-API 실행 경로를 유지합니다.
- 이 목록은 Bluetooth 공용 목록입니다. 사용자가 기기를 삭제하면 Bluetooth 페어링도 함께 삭제되며, 패키지가 자동 삭제하지는 않습니다. 화면 실행에 실패하거나 브리지를 끄면 원래 설정 경로를 사용합니다.
- 1.0.3의 안내 음량 수정을 유지하며, 인증된 1.0.3에서 설정을 보존하는 업데이트·복구 경로를 추가했습니다.

CarPlay·Android Auto 경로 안내
- CarPlay의 ‘순정 형식 턴 표시’를 기본으로 켰습니다. 지원되는 안내를 차량의 회전 종류·각도·거리 막대 형식으로 변환하고, 변환 근거가 없거나 조건을 벗어나면 기존 프로젝션 표시를 사용합니다.
- 한 차선에 여러 진행 방향이 있을 때 휴대전화가 권장한 방향을 화살표별로 표현하도록 보강했습니다. 차선 모양만으로 권장 경로를 만들어내지는 않습니다.
- 차선 묶음과 현재 안내의 연결 관계를 확인하고, 무관하거나 늦게 도착한 차선 정보가 현재 표시를 덮어쓰는 것을 줄였습니다. 차선 목록이 없는 갱신은 명시적인 빈 차선 목록과 구별합니다.
- 휴대전화 안내 중 순정 내비의 차선 출력이 휴대전화 차선을 덮어쓰는 경로를 제한했습니다. 순정 카메라·안전 정보는 별도 처리합니다.
- Android Auto의 계기판·HUD 안내와 USB 메모리·허브 구분을 추가했습니다. 대상 선언과 라이브러리 패치 조건이 맞는 경우에만 적용하며, 이미 해당 순정 안내를 제공하는 구성은 유지합니다.
- Android Auto의 ‘순정 형식 턴 표시’는 선택 기능이며 기본값은 꺼짐입니다.
- Android Auto가 외부 AP의 접속 정보를 사용하는 추가 어댑터는 별도 시험 소스로 보관하고 이번 설치본에는 넣지 않았습니다. 대상 순정 파일의 추가 연결 지점을 모두 재확인하지 못했으므로, 새 맵·무선 AA 기능 플래그가 기존 CarPlay 설치에 영향을 주지 않도록 분리했습니다. 위 TBT·USB 구분 추가가 외장 동글 무선 AA 연결을 새로 활성화하는 것은 아닙니다.

확인 상태와 한계
- 전원·로그·화면 복구 요청·설정·TBT 변경은 소스 및 호스트 시험을 수행했으며 새 변경의 실차 결과는 확인 전입니다.
- 순정 형식 데이터를 보낸다고 모든 계기판·HUD에서 AR 애니메이션이 지원되는 것은 아닙니다. 휴대전화 내비 앱이 제공하지 않는 차선·회전 정보도 생성하지 않습니다.
- 굿바이 화면과 전원 콜백의 정확한 시간 관계, USB 동글 LED의 물리적인 소등을 확인한 것은 아닙니다.
- 순환 로그는 전체 운행의 영구 보존 기록이 아닙니다. 용량 초과 시 오래된 파일이 교체되고, 너무 긴 줄·공간 부족·갑작스러운 전원 차단으로 일부 기록이 빠질 수 있습니다.
- 같은 부팅에서 OFF가 유지된 동안 복귀 콜백을 놓치면 안전하게 OFF를 유지합니다. 다음 명시적 복귀 이벤트 또는 내비 전체 재부팅이 필요할 수 있습니다.
