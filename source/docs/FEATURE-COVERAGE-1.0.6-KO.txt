IONIQ 5 USB CarPlay 1.0.6 — 반영 범위
by blackr / 2026-11-06

화면 정지: 실제 timeout→stop 패턴을 대상으로 화면을 한 번 재부착하는 코드를 추가했습니다.
수동 NAV→CarPlay 복귀와 같은 순정 hide/show 호출을 사용하되 foreground·Surface·소유권을 확인합니다.
호스트 시험과 대상 코드 대조를 완료하며, 차량에서 자동 복구되는지는 적용 후 확인해야 합니다.

AR 진행: 표시 거리만 제공되는 경우에도 기존 회전 타입과 진행 단계를 유지하도록 수정했습니다.
원시 거리 경로는 한국 r8.2와 같은 출력을 유지합니다. 커서의 연속 위치·회전 통과 애니메이션을
새로 만들지는 않았습니다. 입력 거리와 실제 출력 단계 기록으로 원인을 더 구분할 수 있습니다.

설치/수집: 1.0.5 업데이트·삭제 후 신규 설치·같은 1.0.6 자동 로그 수집을 지원합니다.
USB 모델 ID와 실패 사유를 남기며 개인별 장치 식별자나 경로는 내보내지 않습니다.

유지: 1.0.3 안내 음량, 1.0.4 차선/기기목록/전원 이벤트/상시기록, 1.0.5 각도 정규화와
차속 송신 코드 및 순정 TBT·USB 전원 읽기 기록을 유지합니다.

아직 미확인: GPS·차속 표시 전체 지연, 한국 터널 전용 코드와 모든 AR HUD 표현,
오류 콜백 없는 화면 정지, 동글 USB 5V 물리 차단. 모든 upstream 독립 기능을 설치하지는 않습니다.
전체 upstream 검토 이력은 FEATURE-COVERAGE-1.0.4-KO.txt, 개별 변경은 버전별 문서를 보세요.
