CarPlay 1.0.15 설치·기록 수집 / by blackr

USB 자동 실행은 다음 상태를 구분합니다.
- 설치 기록이 없는 경우: NEMESIS 패키지를 신규 설치합니다.
- 지원하는 이전 버전이 설치된 경우: 기존 서명과 설치 기록을 확인한 뒤 업데이트합니다.
- 1.0.15 설치가 완료된 경우: 재설치하지 않고 기록만 USB로 수집합니다.
- NEMESIS에서 삭제한 경우: 완료된 이전 설치 기록을 검증·보관하고 신규 설치합니다.
- 설치 중단, 알 수 없는 버전 또는 손상된 기록: 자동 덮어쓰기를 하지 않고 오류를 남깁니다.

1.0.14에서 1.0.15로 업데이트할 수 있도록 실제 배포 ZIP의 전체 설치 묶음과
서명된 모드 manifest를 고정값으로 확인합니다. 기존 1.0.11 직접 업데이트 및
이전 버전의 지원 범위도 유지합니다. 독립 음소거 패키지와 설정은 수정하지 않습니다.

보관 중인 1.0.13·1.0.14 배포본에는 NEMESIS 표시 버전이 1.0.12로 남아 있었습니다.
이 두 배포본에 한해서 전체 이전 설치 묶음의 고정 해시와 현재 설치된 모드의
HMG 서명을 모두 확인한 뒤 정상 업데이트를 허용합니다. 다른 버전 불일치는
계속 거부합니다. 1.0.15에서는 NEMESIS, 모드, 설치 기록의 버전을 일치시켰습니다.

호스트 시험은 임시 파일 시스템에서 설치·복구·수집 분기를 검증합니다.
차량 설치 성공이나 주행 중 동작을 대신하는 검증은 아닙니다.
