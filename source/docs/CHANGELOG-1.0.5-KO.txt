2026-11-06 / 1.0.4 이후 변경 / 실차 확인 전

차량 차속 전달
- 실제 MICOM 차속 콜백 뒤 OEM PASCD 생성기·전송 경로로 최신 값을 보냅니다.
- 추가 전송은 최소 250ms 간격, 대기 한 건으로 제한합니다. 기존 1초 송신을 유지하므로
  전체 전송 상한은 약 5회/초입니다. 아이폰이 요청한 활성 무선 세션에서만 추가 전송합니다.
- ‘차량 차속 빠른 전달’ 설정을 끄고 재부팅하면 기존 경로만 사용합니다.
- GPS NMEA는 순정 코드에서도 수신 즉시 전달되므로 좌표·시각·센서 주기는 바꾸지 않았습니다.

턴바이턴
- ±180° 밖이라는 이유로 버리던 270°·300° 등의 유효한 선택 각도를 정규화합니다.
- CP 54개 유형 및 AA 정의 유형별 변환·fallback 범위를 TBT-1.0.5-KO.txt에 명시합니다.
- 순정 내비가 쓰는 TBT 숫자 프레임을 기록합니다. 휴대전화 안내 중에는 기록하지 않습니다.
  writer별 같은 값은 생략하고 최대 초당 1건만 기록하며 도로명·좌표는 제외합니다.

화면 복구
- 순정 showDisplay()가 성공한 화면 재부착 뒤 키프레임을 한 번 요청합니다.
- 최소 2초 제한에 걸린 재부착 요청은 잔여 시간 뒤 한 건만 실행합니다.
- 화면 숨김·Surface 교체·세션 종료 시 이전 대기 작업을 취소합니다.
- 기존 디코더 오류·시간 초과 복구 경로를 유지합니다. 주기적 강제 갱신은 없습니다.
- 이미 실행 중인 네이티브 호출은 취소할 수 없으며, 실제 프레임 표시 성공을 보장하지 않습니다.

USB 전원 확인
- AP 시작·정지 시 검증된 동글의 runtime 전원 상태와 확인 가능한 init 트리거를 읽습니다.
- 이 기록은 읽기 전용입니다. 포트 전원·MICOM·드라이버 상태를 변경하지 않습니다.
- 논리 전원 OFF 때 AP와 네트워크 인터페이스를 내리는 1.0.4 동작을 유지합니다.

설치·로그
- 기존 1.0.4의 알려진 빌드에서 업데이트 또는 Uninstall 뒤 신규 설치를 지원합니다.
- 같은 1.0.5가 정상 설치되어 있으면 같은 USB의 Yes는 재설치 대신 기록을 수집합니다.
- 네메시스/HMG-API, 음소거 및 시작 동의 패키지는 별개입니다.
- 동글/AP와 사용자가 정상 확인한 1.0.3 오디오 정책은 유지합니다.
