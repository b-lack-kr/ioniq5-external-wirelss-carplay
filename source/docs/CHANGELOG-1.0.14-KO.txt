1.0.14 — 기본 TBT 유지와 추천 차선·정션뷰 수신/출력 분리
2026-11-08 / by blackr

기준 정정
사용자가 확인한 1.0.9 정상 범위는 기본 회전·거리 안내입니다. 추천 차선과 정션뷰는 1.0.9에서도 작동하지 않았습니다. 따라서 1.0.9로 되돌리는 것만으로 이 두 기능을 복구했다고 설명하지 않습니다. 1.0.13은 기본 TBT 경로 복원 후보였으며 차량에 설치하지 않았습니다.

이번 변경
- 기본 회전·거리·남은 거리·HUD 목록은 1.0.9 기반 처리 정책을 유지합니다. 1.0.11의 주기적인 화면 재전송과 별도 차선 거리 API는 다시 켜지 않습니다.
- 차선 입력을 순정 알림과 별도 iAP2 관찰 경로로 받습니다. 원래 CarPlay 데이터 전송 후 제한된 큐로 복사하고 다른 작업 스레드에서 파싱합니다. 전송 콜백에서 파싱하거나 기본 통신 잠금을 잡고 처리하지 않습니다. 조각 유실/큐 초과/소유권 변경 때 부분 메시지를 버리고 다시 동기화합니다.
- 순정 차선 알림만 오는 경우도 처리하며, 같은 세션·안내 컴포넌트·차선 인덱스가 맞는 데이터만 표시 후보로 사용합니다. 순정 알림이 동일 레코드를 제공하면 해당 데이터를 우선합니다.
- 차선 상태(사용 불가/추천/우선 추천)와 강조 방향을 각각 표시합니다. 사용 불가는 회색, 추천 방향은 흰색, 우선 추천 방향은 파란색으로 변환합니다. 입력에 없는 추천 차선을 만들어내지 않습니다.
- 명확한 차선 조합과 진행 방향이 있을 때 지원되는 정션 템플릿을 선택합니다. 차선 번호가 불완전하거나 오래됐거나 다른 안내의 데이터면 차선 기반 정션 그림을 선택하지 않습니다. 순정 지도 전체 형상이나 실제 차로 위치를 재현하는 기능은 아닙니다.
- 기본 TBT/HUD 전송 뒤 추천 차선·정션 패턴을 별도 출력 스레드에 넘깁니다. 진행 중 1건과 최신 대기 1건만 유지합니다. 선택/파싱/출력 오류를 각각 기록하고 기본 회전 안내로 전파하지 않습니다. 성공한 같은 출력은 중복 전송하지 않고, 관측 가능한 실패는 다음 실제 입력에서 재시도합니다.
- 종료·재탐색·안내 앱 변경·순정 내비 인계 시 이전 차선과 패턴의 소유권을 검사합니다. 연결이 끊기거나 순정 내비로 인계되면 대기 중인 부가 출력/지우기를 즉시 취소해 새 안내를 지우지 않습니다. 연결을 유지한 길안내 종료에서는 기본 TBT와 함께 차선/패턴을 지웁니다. 이미 상대 서비스가 받아 실행 중인 IPC를 취소할 수는 없으며 이후 오래된 출력은 차단합니다.
- USB 수집에 추가 기능 오류와 수신 상태를 포함합니다. 새 로그는 미리 정한 숫자/상태만 기록하며 원시 CarPlay 데이터나 목적지 문자열을 내보내지 않습니다.

유지한 기능
1.0.12의 추가 250ms 차속 대기 제거, 최신 실제 차속 전달, 전원/문 상태를 이용한 AP 종료, 기존 음악·안내 음량 처리, 5GHz 외부 동글, 수동 ADB 및 개발 로그를 유지합니다.
공개 설정은 AR 턴 표시(기본 OFF, CarPlay/Android Auto 공통)와 외부 USB Wi-Fi 동글 사용(기본 ON) 두 개입니다. 기본 TBT/추천 차선/지원되는 정션 그림은 AR OFF에서도 동작하도록 구성합니다.
AR ON은 CarPlay의 기존 457m 근사 정책입니다. Android Auto의 50m/600m 정책과 전환 거리가 다릅니다. 0m에서 커서가 회전 지점을 통과하는 순정 애니메이션이 구현됐다는 뜻이 아닙니다.

설치
인증된 1.0.11/12/13에서 1.0.14로 업데이트하거나 NEMESIS Uninstall 후 신규 설치합니다. 이전 복구 기록은 보존합니다. 동글 드라이버 등 외부 입력은 기존과 동일합니다. HMG-API 1.0.2 사용자는 runtime을 다시 설치할 필요가 없습니다.
설치가 끝나면 동글을 꽂고 내비를 재부팅합니다. 같은 1.0.14 USB를 다시 꽂아 Yes를 누르면 재설치하지 않고 로그만 수집합니다. 음소거 패키지는 별개로 유지합니다.

확인 범위와 남은 항목
이번 파일은 로컬 빌드·호스트 검증을 거친 차량 시험용 설치본입니다. 추천 차선/정션뷰의 차량 표시, TBT 소실 및 화면 멈춤 개선을 실차 성공으로 표시하지 않습니다.
출력 함수가 정상 복귀해도 순정 프레임워크가 내부 RemoteException을 삼키는 경우까지 성공 여부를 알 수는 없습니다. 함수 복귀는 계기판/HUD 수신 확인(ACK)이 아닙니다.
한국판 순정 라이브러리의 차선 메시지 등록 오류는 미확정입니다. 한국 DiPO 수신 필드는 확인했지만 native .so가 없어 upstream과 같은 오류인지 확인할 수 없습니다. 별도 비동기 관찰 경로는 이 입력 불확실성을 줄이기 위한 구현입니다.
USB 단자 물리 5V 차단, 모든 교차로의 정션뷰, 0m 회전 통과 커서 애니메이션은 해결 완료 항목이 아닙니다. AP 종료 정책은 실차 전원 이벤트 확인이 필요합니다.

출처
HMG-API/Leafia 및 Seogaemo의 기존 출처·AGPL 표기를 보존합니다. 대응 소스, 빌드·설치 스크립트를 함께 제공합니다. 타인의 펌웨어 바이너리, 지도 데이터, 개인 차량 기록은 배포 ZIP에 넣지 않습니다.
