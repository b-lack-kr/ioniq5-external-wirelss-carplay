1.0.8 TBT 적용 범위

현상: 거리 숫자는 감소하지만 AR 화면의 차량 위치 커서는 고정됩니다.
수정: 한국 r8.2 main sideStreet·10단계 bar·명시0각 fallback을 반영하고, 검증되지 않은 trap100 실험은 제거했습니다.
HUD F2 projection 데이터와 2C 거리 전송은 유지합니다. 회전 종류를 목적지 도착으로 속이거나 임의 시간으로 커서를 움직이지 않습니다.

기본 시퀀스(우회전, 유효한 각도90, 순정 형식 ON)
458m: projection67 / sideStreet65535 / bar0
457m: native13 / angle90 / sideStreet0 / bar90
100m: native13 / angle90 / bar20
45m, 1m, 0m: native13 / angle90 / bar10
다음 항목은 다음 maneuver의 종류·거리로 전환합니다. 거리0만으로 목적지 도착 상태를 만들지 않습니다.
이 표는 전송값이며 계기판의 커서 모션을 입증한 결과가 아닙니다.

Apple 문서의 별도 회전 단계와 현재 구현
CPNavigationSession.maneuverState는 회전에 접근·진입하는 상태를 나타냅니다.
현재 수신기는 item2를 읽지만 차량 PREPARE/통과 애니메이션 필드로 변환하지 않습니다.
한국 r8.2도 해당 값은 읽어 로그에만 사용합니다. API 이름만으로 숫자 대응을 정하지 않습니다.
이번 후보는 수신 여부와 raw 상태를 기록해 실제 네이버/카카오 앱 송신 상태를 확인할 수 있게 합니다.

실차 확인 절차
1. 설치 후 동글로 재부팅합니다.
2. 순정 내비로 안내를 시작해, 원래 커서가 움직이는 회전 한 곳을 통과합니다. CarPlay 앱 길안내는 종료한 상태여야 순정 출력 기록으로 구분됩니다.
3. CarPlay 길안내로 같은 유형의 회전을 확인하고 발생 시각을 기록합니다.
4. 패키지를 지우기 전에 동글을 빼고 설치 USB를 꽂아 Yes → 기록 수집 완료를 기다립니다.
5. USB를 Mac으로 가져옵니다. 파일 교체는 필요 없습니다.
순정 numeric 관측은 writer당 최대1Hz라 아주 짧은 전이는 빠질 수 있습니다. API 정상 반환은 계기판 수신 ACK가 아닙니다.
