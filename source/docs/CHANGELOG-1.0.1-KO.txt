CarPlay 1.0.1 · by blackr

Android 준비 완료 전에 검증된 USB Wi-Fi 드라이버를 먼저 로드하고 초기 실패 기록을 보강했습니다.
임시 폴더 전체 대신 실제 사용하는 파일을 확인하여 무관한 보조 링크가 부팅을 막지 않도록 했습니다.
신규 설치 시 두 자동 시작 서비스의 등록과 활성화 상태를 확인합니다.
1.0.0 삭제 후 남은 작업 폴더·설정을 보관하고 새로 설치할 수 있습니다.
USB의 Mac 보조 파일 ._LICENSE 등으로 설치 완료 확인이 실패하던 경로를 수정했습니다. 내부에 manifest로 복사한 파일을 엄격하게 검증합니다.
정상 부팅 및 연결 대기 팝업은 표시하지 않습니다.

음소거 1.1.0을 통합했습니다. 음소거로 멈춘 음악은 버튼 또는 볼륨 조절로 음소거가 실제 해제되면 재생됩니다.
기존 음소거 1.0.0을 검증 후 업데이트하고, 이미 설치된 동일1.1.0은 유지합니다.
CarPlay1.0.1과 음소거1.1.0의 서명된 실행 파일은 사용자가 시험한 것과 동일합니다.
2026-11-05 사용자가 대상 차량에서 설치·동작 확인을 보고했습니다. 통합 설치기의 업데이트 조합과 PC 준비 도구는 별도로 호스트에서 검사했습니다.
