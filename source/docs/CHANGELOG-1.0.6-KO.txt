IONIQ 5 USB 무선 CarPlay 1.0.6 — by blackr
2026-11-06 / 1.0.5 이후 변경 / 차량 적용 후 확인 필요

확인된 증상
사용자가 화면 정지 후 다른 앱으로 나갔다 CarPlay로 돌아오면 복구됐다고 확인했습니다.
1.0.5 차량 기록에서 13:45:30, 13:46:11 화면 timeout 직후 screen_stopped가 발생했습니다.
해당 구간에는 같은 CarPlay 세션과 AP 연결이 유지됐습니다. 키프레임 요청의 반환은 0이었으나
화면 재진입 전까지 정지 상태였습니다. 앞선 USB 인식 변경 기록과는 별개입니다.

화면 출력 복구
- 활성 무선 CarPlay에서 timeout 이후 2초 이내 screen_stopped가 이어질 때 재부착을 예약합니다.
- 250ms 대기 후에도 CarPlay 화면이 활성 상태이고, 화면 소유권과 Surface가 유효한 경우에만
  순정 hideDisplay → showDisplay를 한 번 실행하고 새 키프레임을 요청합니다.
- 단일 작업 스레드와 최소 10초 재부착 간격을 사용합니다. 주기적으로 화면을 껐다 켜지 않습니다.
- 앱 이탈, 화면 숨김, Surface 교체, 소유권 변경, 세션 종료 시 대기 중인 처리를 취소합니다.
- Wi-Fi/AP와 CarPlay 세션을 재시작하지 않습니다. 안내 음량과 기존 동글 구동 방식을 유지합니다.
- 이미 진입한 네이티브 호출은 중간 취소할 수 없습니다. 반환 0은 실제 새 영상 표시의 증거가
  아니므로 복구 요청·결과와 이후 screen_started 등을 함께 기록합니다.

AR/TBT 거리 처리
- 휴대전화가 원시 미터 대신 표시 거리만 갱신할 때 순정 형식의 회전 표시가 해제되던 경로를 수정합니다.
- 원시 거리를 우선하고, 없으면 검증된 표시 거리와 단위를 미터로 변환해 기존 진행 단계에 사용합니다.
- 기존 한국 r8.2의 457m 구간·10~90 단계는 유지합니다. 잘못된 값과 범위 초과를 거부합니다.
- 실제 전송한 회전 유형·각도·진행 단계·거리와 raw/display 출처를 최대 초당 한 번 기록합니다.
- 이 수정이 사용자의 정지 커서 원인이었다는 증거는 아직 없습니다. 회전 지점을 지나가는
  차량 위치 애니메이션이나 모든 AR HUD 동작을 완성한 버전이라고 안내하지 않습니다.

기록 및 설치
- 영상 재부착 실행과 반환값, 실제 TBT 출력, USB 인식 실패 사유와 AP 확인 결과를 USB에 보존합니다.
- 도로명·좌표·SSID·전화기 식별자는 내보내지 않습니다. USB 모델 VID:PID와 유한 상태값은 기록합니다.
- 알려진 1.0.5에서 설정을 유지하는 업데이트와 Uninstall 뒤 신규 설치를 지원합니다.
- 같은 1.0.6가 정상 설치되어 있으면 동일 USB의 Yes는 재설치 대신 로그를 수집합니다.
- printf 없는 차량 셸 대응을 유지합니다. HMG-API 1.0.1 이상이면 되며 기존 1.0.2를 사용합니다.
- 음소거·시작 동의 패키지는 별개이며 자동 설치나 버전 검사를 하지 않습니다.

변경하지 않은 범위
차량 GPS/차속 송신, 전원 OFF/ON 연동, 동글 드라이버, 정상 확인된 1.0.3 안내 음량 정책은 유지합니다.
GPS·지도 전체 지연, 한국 터널 전용 아이콘 전체 매핑, 모든 AR HUD 표현, 오류 신호 없는
화면 정지의 감지, USB 5V 물리 차단은 이번 변경으로 해결 완료된 항목이 아닙니다.
