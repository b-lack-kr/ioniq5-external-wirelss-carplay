1.0.12 — 설정 단순화·차속 즉시 송신·전원 종료 판정 보완
2026-11-08 / by blackr

설정과 기본 안내
- 공개 설정을 ‘AR 턴 표시’와 ‘외부 USB Wi-Fi 동글 사용’ 두 개로 줄입니다. 변경 후 재부팅이 필요합니다.
- AR은 기본 OFF이며 CarPlay와 Android Auto에 같은 설정을 적용합니다. ON일 때 일반 회전 50m, 진입·진출로 계열 600m 접근 정책을 사용합니다. 순정의 모든 동적 조건을 재현한 값은 아닙니다.
- 기본 턴바이턴, 거리, 추천 차선과 지원되는 CarPlay 정션 그림은 AR OFF에서도 동작하도록 분리합니다. 예전 개별 기능의 OFF 설정이 이 기능들을 막지 않도록 했습니다.
- Bluetooth/Wi-Fi 연결 보정, 오디오/내비 안내 음량, AA USB 장치 구분, 차속 보강은 내부 기본 동작으로 유지합니다. 음소거 패키지는 별도 설치·삭제합니다.

추천 차선
- CarPlay의 현재 안내에 연결된 차선 방향·highlight·LaneStatus를 계기판 형식으로 변환합니다. 좋은 차선의 권장 방향은 흰색, 우선 차선(status 2)은 파란색, 비추천 또는 경로 외 방향은 회색입니다.
- Android Auto의 실제 추천 방향 마스크는 흰색/회색으로 표현합니다. AA 입력에는 CarPlay의 우선 차선 상태와 같은 신호가 없어 파란색을 임의로 만들지 않습니다.
- 앱이 충분한 차선/추천 정보를 보내지 않으면 추측해 강조하지 않습니다. 안내 종료 및 명시적인 차선 없음은 이전 표시를 해제합니다. AR 스위치와 별개로 유지합니다.

차속
- 기존 차량 차속 추가 송신의 최소 250ms(초당 최대 4회) 대기를 제거합니다. 유효한 새 OEM 차속 이벤트를 받으면 즉시 송신 대상으로 삼습니다.
- 같은 차속의 반복 콜백은 추가 송신하지 않고 순정 주기 송신을 유지합니다. 전송 중 새 이벤트가 들어오면 최신 값 하나로 합칩니다. 동시 송신은 하나만 허용하며 오래된 값의 대기열을 쌓지 않습니다.
- 송신 문장을 만든 사이에 재연결되면 이전 세션의 문장을 폐기하고 새 세션 최신값만 송신합니다. 실제 세션, 휴대폰 요청 및 유효한 차량 데이터 조건은 유지합니다. GPS나 차속을 추측해 생성하지 않습니다. 휴대폰 내비 앱의 화면 지연까지 0ms가 된다는 뜻은 아닙니다.

앱 로딩 경계
- Android Auto 앱 파트가 CarPlay 앱 파트의 클래스를 직접 참조하던 경로를 분리합니다. 각 앱의 클래스 로더 안에 필요한 도우미를 배치합니다.
- 이 경계 위반은 코드에서 확인한 호환성 문제입니다. 1.0.11에서 보고된 CarPlay TBT 소실 및 화면 멈춤의 실차 원인이라고 확정하지 않습니다.

시동 종료와 AP 차단
- 순정 Micom 전원 상태와 BCM 시동/운전석 문 상태를 읽는 리스너를 추가합니다. 제어 명령을 보내지 않습니다.
- 시동 ON→OFF를 실제로 관찰한 후 운전석 문이 열리거나, 순정 시스템 종료 상태가 확인되면 이 패키지가 만든 AP와 인터페이스를 중지합니다. ACC 전원 유지 상태만으로 바로 차단하지 않습니다.
- DiPO 콜백과 전원 리더의 실제 상태 변경 시각을 비교합니다. 오래된 ON 기록과 반복 조회가 더 새로운 OFF를 덮어쓰지 못하게 했습니다.
- 같은 부팅 안에서는 리더/서비스가 재시작해도 확인된 OFF를 유지합니다. 등록 직후 초기 상태 통보는 새로운 시동 ON으로 취급하지 않고, 이후 확인된 ON 전환 때 다시 시작합니다.
- AP가 살아 있는 정상 루프의 전원 확인 간격은 약 3초이며, 리더 조회 간격은 2초입니다. 실제 종료 이벤트 수신과 서비스 상태에 따라 차단 시점이 달라질 수 있습니다.
- USB 단자의 물리적인 5V 전원을 끄는 기능은 아닙니다. 목표는 무선 AP와 CarPlay 재접속 차단이며 LED가 완전히 꺼지는지는 동글 하드웨어에 따라 다릅니다.
- 전원 판정 이유와 리스너 사용 가능 여부를 기존 용량 제한 로그에 남기고 같은 설치 USB로 수집합니다.

설치와 기록
- 정확한 1.0.11 배포본을 인증해 갱신하고 이전 설치 기록·연결 설정·복구 자료를 보존합니다. 기존 1.0.9/1.0.10 업그레이드 경로도 유지합니다.
- NEMESIS에서 Uninstall한 뒤 신규 설치하는 경로를 지원합니다. 동일한 1.0.12 USB를 다시 꽂고 Yes를 누르면 재설치하지 않고 기록을 수집합니다.
- 설치 실패·중단 시 이전 인증 설치본으로 복구하는 호스트 회귀 시험을 수행했습니다.

실차 확인이 필요한 항목
- 차량 ADB 연결 없이 준비한 설치본입니다. 1.0.11의 TBT 소실과 잦은 화면 멈춤이 해결됐다고 확인하지 않았습니다.
- 추천 차선의 실제 색/방향, AR OFF의 기본 안내와 정션 그림, 종료 후 AP 차단 및 다음 시동 재시작은 실차에서 확인해야 합니다.
- 0m에서 커서가 회전 지점을 통과하는 애니메이션, 모든 교차로의 정션 그림, 전체 터널 아이콘 매핑은 해결 완료 항목이 아닙니다.
- 기존 화면 복구 경로와 용량 제한 로그 수집은 유지합니다. 새로운 차량 기록을 받기 전에는 영상 멈춤 원인을 추정으로 고치지 않습니다.

출처
HMG-API 및 HMG-Seogaemo v0.1.47(7616e43f669916445f151a7aeb279b32ea09cd4b)의 기존 적용 내용을 유지합니다. 원저작자 표기와 AGPL 조건, 수정 소스 및 빌드·설치 스크립트를 함께 제공합니다.
