CarPlay 1.0.2 · by blackr
2026-11-05 차량 검증용 후보. 공개 GitHub 릴리스는 아직 갱신하지 않았습니다.

변경
- HMG-API 1.0.1에 고정되어 1.0.2 설치를 막던 검사를 수정했습니다. 최소 1.0.1 이상, 데몬 응답 및 필요한 실행 파일을 확인하며, NEMESIS 누락은 별도로 안내합니다. 음소거 1.1.0 설치기의 같은 제한도 수정합니다. 기존 HMG-API 1.0.2를 그대로 사용할 수 있습니다.
- 정식 1.0.1에서 연결 설정을 유지하며 업데이트하고, 실패하면 기존 상태로 복구합니다. NEMESIS/HMG-API를 다시 설치하지 않습니다.
- 순정 전원 종료 상태에서 외부 AP/DHCP와 동글 인터페이스를 중지하고, 전원이 돌아오면 재시작합니다. 굿바이 애니메이션과의 정확한 시점은 실차 확인이 필요합니다. USB 5V 차단은 아닙니다.
- 추천 차선 각도를 버리던 처리를 수정하고 중복 화살표를 제거했습니다. 목록 없는 차선 메시지가 화면을 지우지 않습니다.
- 같은 방향의 중복 안내 문구를 제거했습니다.
- 진입로·진출로와 선택 각도가 있는 고속도로 분기 매핑을 추가했습니다. 53개 유형의 검토표는 TBT-MAPPING-1.0.2.txt를 참조하세요.
- 직진/도로 유지 유형과 함께 전달되는 터널 문구를 보존합니다. 순정 터널 전용 아이콘 번호는 아직 확인되지 않았습니다.
- 무선 CarPlay의 안내 음성 채널이 먼저 열리고 나중에 안내 시작 신호가 오는 순서에서도 순정 안내 음량 채널을 선택하도록 보정합니다. 실제로 열린 채널의 수명을 추적하며, 종료 후 늦게 온 신호로 채널을 다시 열지 않습니다.
- 순정 CarPlay 음악 채널 요청이 실패했는데도 성공 상태를 기록하던 경로를 보정합니다. 다음 순정 요청에서 다시 시도할 수 있게 하며, 주기적인 강제 재시도는 추가하지 않습니다.
- GPS/차속 입력과 전달 간격, 안내 오디오 채널·MICOM 요청·볼륨 키 기록을 추가했습니다. 위치 지연은 아직 수정하지 않았고, 음량 보정의 실제 효과는 차량 검증이 필요합니다.
- USB 재삽입 시 개인정보를 제외한 현재/영구 로그와 고정된 순정 프로그램 파일을 수집합니다. 코드 파일은 최대 8개, 총 96MiB로 제한합니다.
- 음소거 일시정지·자동 재생 1.1.0은 기존 검증 바이너리를 그대로 사용합니다.

검증
오디오 보정은 실제 hook 코드 통합 35개 시나리오와 상태 전환 24개 검사를 통과했습니다. 사용한 신규 맵 16개를 실제 대상 DEX의 선언·타입·시그니처와 대조했습니다.
Java/Dalvik 035 컴파일 및 서명 검증, AP 22개, 차선 24개, 안내 프레임 회귀, 설치 트랜잭션 36개, 수집기 및 코드 파일 제한 시험을 통과했습니다.
상위 설치 조정기 37개(미실행 없음), 음소거 설치기 호환성 46개를 통과했습니다. HMG-API 1.0.2 설치·반복 실행·복구와 기존/신규 음소거 패키지 처리를 모의 검증했습니다.
실차 설치·연결·굿바이 시점·차선 강조·터널 아이콘·안내 음량·GPS 지연은 별도 확인 대상입니다.
