NEEV 260902 / CarPlay 1.0.3 안내 음량 처리

후속 확인: 아래 내용은 1.0.3 제작 당시의 기록입니다. 2026-11-06 사용자가
실제 내비 안내 음량 조절 성공을 확인했습니다. 1.0.4도 이 오디오 코드를 유지합니다.

사용자가 확인한 현상
음악 음량은 정상이고, 네이버 지도의 연속 음량 조절용 안내음도 내비 음량에 반응합니다.
하지만 실제 길안내 음성은 내비 음량에 반응하지 않습니다. 이번 변경은 추가 비교 수집을
요구하지 않고, 확인된 순정 오디오 호출과 사용자가 요청한 정책을 적용한 수정입니다.

변경
이 모드의 무선 CarPlay 세션에서 Alt 보조 오디오가 Compatibility, Default, Media,
Alert 형식으로 들어오면, 해당 순정 콜백의 첫 MICOM 19 요청을 내비 채널 13으로 바꿉니다.
순정 종료 처리가 같은 채널을 정리하도록 대기 상태 iZ도 요청 전에 1로 맞춥니다.
순정 duck/unduck 상태에 따른 보조 채널 전환과 시작 후 재할당은 제거했습니다.
이미 채널 13을 요청한 경우에는 그대로 둡니다. 요청 실패 시 재시도, 19로의 우회,
타이머, 직접 PCM 게인 조절을 추가하지 않습니다.

범위
같은 스레드의 콜백·오디오 관리자·세션·세대가 일치하는 요청만 바꿉니다.
통화·Siri·전원·텔레매틱스 등의 순정 상태 검사를 유지합니다.
Main/MainHigh 음악, Telephony, SpeechRecognition, Unknown, 유선 세션은 변경하지 않습니다.
기존 음악 시작 실패 시 상태가 고정되지 않도록 한 보정은 유지합니다.

한계
CarPlay 콜백에는 아이폰의 원래 앱 식별자가 없습니다. 따라서 특정 앱의 모든 소리를
판별하는 방식은 아닙니다. Alt로 전달되는 별도 알림음도 내비 음량을 사용하게 됩니다.
Main 음악 스트림에 이미 합쳐져 온 안내 음성은 이 단계에서 분리할 수 없습니다.
56개 호스트 시나리오로 호출 순서·범위·종료·오류 처리를 검증했습니다.
실제 차량의 안내 음량 반응은 아직 검증하지 않았습니다.

기록
기존 차량 내부 기록과 USB 수집 기능을 유지합니다. 설치 중 기록 수집은 실행하지 않습니다.
설치와 수집은 별도 모드이며, 사용자가 보통처럼 안내 음량을 조절한 결과로 먼저 확인합니다.
1.0.2의 오디오 문서는 이전 동작의 기록이며 이 문서가 현재 정책입니다.
