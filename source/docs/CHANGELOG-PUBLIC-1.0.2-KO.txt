공개 CarPlay 1.0.2 / by blackr / 2026-11-08

내부 개발판 1.0.15의 본체를 공개 1.0.2로 배포합니다. 내부 1.0.16~1.0.18에서 추가한 CarPlay 버튼과 수동 연결 서버는 포함하지 않습니다.

- 내비 안내 음량 제어, 초기 0m 거리, 차선 거리 분리, 일반 회전 AR 300m 기준을 반영했습니다.
- 차량 차속을 CarPlay RMC 속도 입력에 반영하고, 굿바이 AP 종료·웰컴 재연결 준비와 진단 로그를 포함했습니다.
- 잘못된 범용 정션 그림 선택을 중단했습니다. 정션 전체 매핑과 화면 멈춤은 해결 완료 항목이 아닙니다.
- 음소거·자동 재생은 별도 패키지로 분리합니다. 기존 설치 상태를 유지하며 필수 검사·자동 설치를 하지 않습니다.
- 공개 1.0.1 업데이트, 신규 설치, 같은 공개 1.0.2 USB 재삽입 시 로그 수집을 지원합니다.
- 과거 내부 개발판 1.0.2 기록과 구분되는 공개 설치 기록을 사용합니다.
- Windows/macOS 준비 도구의 파일 교체 방식과 GUID·AppleDouble 수정은 유지합니다. 포맷·파티션 생성은 하지 않습니다.

기준 차량에서 사용자 확인한 항목과 남은 제한은 [README](README.md#확인-범위)를 참고하세요.


이전 CHANGELOG-1.0.2-KO.txt는 내부 개발판의 당시 기록입니다. 공개 1.0.2와 구분합니다.
