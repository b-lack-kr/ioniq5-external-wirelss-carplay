1.0.15 — 초기 거리·차량 차속 입력·AR 전환 수정과 주행 진단 보강
2026-11-08 / by blackr

이번 변경
- 처음 안내를 시작할 때 아직 받지 못한 거리를 0m로 표시하지 않습니다. 유효한 73m 등의 입력을 받으면 차량 이동 여부와 무관하게 표시하며, 실제 0m는 그대로 표시합니다.
- 추천 차선 옆 거리는 다음 회전까지의 거리와 별개입니다. 다음 회전이 12km 뒤여도 차선 안내 교차로는 371m 앞일 수 있습니다. 1.0.11의 잘못된 거리 복사를 제거한 정책을 유지합니다. 휴대폰이 해당 교차로의 독립 거리를 전달하는지는 추가 확인이 필요하며, 두 거리를 다시 복사하지 않습니다.
- 차선 수만으로 범용 정션 그림을 선택하던 경로를 끕니다. 실제 우측 진출을 다른 U자형 그림으로 표시할 수 있기 때문입니다. 기본 회전·추천 차선은 유지하며, 명시적 교차로 각도가 있으면 그 정보를 사용합니다. 사용자가 검토할 그림 매칭 도구와 수동 매핑은 차기 버전에 반영합니다.
- 일반 회전 AR 전환을 CarPlay/Android Auto 공통 300m 이하로 맞춥니다. 사용자 순정 내비 실측을 반영하며, 고속도로와 정션 그림의 별도 표시 조건까지 모든 도로에서 같다고 보장하지 않습니다. 교차로의 각도 정보가 충분하면 회색 도로와 선택 경로를 표현합니다. 순정 AR 커서도 고정된다는 사용자 확인에 따라 가상의 회전 통과 애니메이션을 추가하지 않습니다.
- 유효한 차량 차속 콜백을 무선 CarPlay에 전달하는 추가 송신 경로의 세션 전환 조건을 고칩니다. 불필요한 추가 250ms 대기를 제거한 정책을 유지합니다.
- 무선 CarPlay가 요청한 RMC 위치 문장의 속도 필드만 같은 요청·세션에서 관측한 정상 차량 차속으로 맞추고 체크섬을 갱신합니다. GPS 좌표·시각·방향은 유지합니다. 비정상 값, 유효하지 않은 위치, 요청/세션 전환 중에는 원래 문장을 사용합니다. 임의로 3km/h를 더하지 않습니다. iPhone이나 앱이 자체 위치 속도를 선택할 수 있으므로 화면 속도가 계기판과 일치하는지는 실차 확인이 필요합니다.
- 실제 WelcomeGoodbye 앱의 굿바이 시작 신호에서 외부 AP를 종료하고, 웰컴 시작에서 재연결 준비를 요청합니다. 정확한 한국판 앱·프로세스·UID·ODEX 핀으로 범위를 제한합니다. 영상 리소스는 바꾸지 않으며 애니메이션 종료 신호를 재시작으로 오인하지 않습니다.
- 전원·ACC·문 상태와 AP 종료 판단의 근거를 제한된 로그에 기록합니다. 이전 버전의 최신 전원 결정 우선 정책을 유지합니다. 무선 AP 종료와 USB 단자의 물리 5V 차단은 서로 다르며, 물리 전원 차단을 구현한 버전은 아닙니다.
- 화면 멈춤 원인을 구분할 수 있도록 메인 스레드 응답, 작업 큐 지연, Surface 상태, 디코더 콜백과 제어 패킷의 숫자 요약을 기록합니다. 제어 패킷 수는 영상 프레임 수가 아닙니다. 원인이 확인되지 않은 조용한 화면 멈춤을 해결 완료로 표시하지 않습니다.
- TBT 거리·차선 입력·선택·출력, 차량/GPS 속도 입력과 송신 결과, 순정 카메라 경고 필드를 제한된 숫자 로그에 남깁니다. 같은 버전 USB 재삽입으로 수집할 수 있습니다. 원시 위치 문장·목적지·전화번호를 새 진단에 기록하지 않습니다.
- 순정 Navi의 카메라·제한속도 경고는 계속 유지합니다. 자유주행 또는 남아 있는 순정 경로의 경고가 CarPlay 경로와 다를 수 있습니다. 확인한 CarPlay TBT 입력에는 전체 경로나 카메라 정보가 없어, 우회전 경로와 무관한 직진 카메라를 정확히 제외하는 기능은 아직 구현하지 않습니다. 경고 출처와 필드를 기록해 확인합니다.
- 순정 내비가 안내를 넘겨받은 뒤 대기 중이던 CarPlay 종료 작업이 기본 TBT·HUD·남은 거리 표시를 지우지 않도록 소유권을 다시 검사합니다.
- NEMESIS 표시 버전과 설치본 버전을 1.0.15로 일치시킵니다. 이전 1.0.13/14의 잘못된 표시 버전은 정확한 배포본과 서명을 확인하는 경우에만 정상 업데이트를 허용합니다.

유지
5GHz 외부 동글 방식, 연결 설정, 음악·내비 안내 음량 수정, 수동 ADB를 유지합니다. 음소거/자동재생은 별도 패키지이며 CarPlay 설치가 그 설치를 요구하지 않습니다.
공개 설정은 AR 표시(기본 OFF, CP/AA 공통)와 외부 동글 사용(기본 ON)입니다. AR OFF에서도 기본 TBT와 실제 입력 기반 추천 차선 처리는 유지합니다.

설치와 기록
현재 차량의 인증된 1.0.11에서 직접 업데이트할 수 있습니다. 지원하는 이전 버전 업데이트, NEMESIS Uninstall 후 신규 설치, 같은 정확한 1.0.15에서 USB 자동 로그 수집을 지원합니다. 이전 복구 기록은 보존합니다. 설치된 HMG-API 1.0.2는 그대로 사용합니다.
설치 후 새 훅을 적용하려면 내비 재부팅이 필요합니다. 동글 연결 후 시험하고 같은 USB를 꽂아 Yes를 누르면 재설치 없이 기록만 수집합니다. 설치 중단/손상 상태는 정상 설치로 취급하지 않습니다.

확인 범위
로컬 빌드·호스트 회귀 시험은 변환, 세션 경계, 소유권, 로그 제한, 설치·복구 경로를 검증합니다. 실차 표시와 iPhone 수신 확인을 대신하지 않습니다. 출력 API가 정상 복귀한 사실은 계기판/HUD 수신 ACK가 아닙니다.
추천 차선의 독립 교차로 거리, 모든 정션 그림, 앱의 최종 속도 표시, 화면 멈춤의 원인, 문을 연 뒤 AP 종료는 이번 실차 확인 항목입니다.

출처 및 대응 소스
HMG-API, Leafia Plus, Seogaemo의 기존 원저작자와 라이선스를 보존합니다. Seogaemo 0.1.48은 검토했으나 0.1.47 대비 CarPlay/TBT/AR/차속/전원 수정이 없었습니다. 삭제한 모듈 복구 UI 및 관리 명령 변경을 이 CarPlay 패키지에 임의로 포함하지 않습니다.
https://github.com/seogaemo/hmg-seogaemo/compare/v0.1.47...v0.1.48
USB ZIP과 대응 SOURCE ZIP 및 라이선스를 함께 제공합니다. 개인 주행 기록·순정 펌웨어·지도 그림·타사 동글 드라이버는 공개 ZIP에 넣지 않습니다.
