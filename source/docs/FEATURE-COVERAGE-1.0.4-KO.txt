IONIQ 5 USB 무선 CarPlay 1.0.4 — 기능 검토 및 반영 범위
by blackr / 검토 기준: 2026-11-06

이 문서는 HMG-API main의 기능과 전체 PR 목록, HMG Leafia Plus 및 제공된 한국판
1.0.5.NEEV.KOR.03-r8.2를 비교해 이번 패키지에 무엇을 반영했는지 설명합니다.
전체 목록을 검토했지만 모든 제안을 설치하거나 모든 차량에서 동작을 보장하는 문서는 아닙니다.
새 변경의 소스·호스트 시험과 실제 차량 시험 결과는 구별합니다.
Android Auto 외부 AP 연결 어댑터는 별도 시험 소스로 보관하며 이번 설치본에는 포함하지 않습니다.

검토한 upstream 기준
- HMG-API main 고정 시점:
  https://github.com/VysseCodes/HMG-API/tree/180185de2c57afb2cca4858d0be7828e8f1051d6
- 해당 시점 전체 PR 31개: 병합 22개, 열린 PR 7개, 병합되지 않고 닫힌 PR 2개.
- 모든 PR의 주제·상태를 검토했고, 현재 기능과 직접 관련된 변경은 코드까지 비교했습니다.
  모든 HMG-API core 코드와 모든 PR의 모든 줄을 감사했다는 뜻은 아닙니다.
- 기존 HMG Leafia Plus는 보관 상태이며 공식 후속 프로젝트는 HMG-API입니다.
  https://github.com/VysseCodes/HMG-Leafia-Plus
- 한국판 r8.2는 제공된 첨부 파일을 정적으로 분석했습니다. 실행·설치하지 않았고,
  한국판의 빌드 무결성 정보가 차량 동작까지 보증한다고 해석하지 않았습니다.

기존 동글 구성은 유지합니다
- 현재 사용하던 지원 USB Wi-Fi 드라이버와 이 패키지의 AP 시작 방식을 기본으로 유지합니다.
- ‘외부 USB Wi-Fi 동글 사용’은 기본 켜짐입니다. 끄면 이 패키지가 외부 AP를 시작하지 않습니다.
  설정을 적용하고 서비스를 재시작하거나 내비를 재부팅해야 반영됩니다.
- 내장 Wi-Fi가 없는 차량에서 이 설정을 끄면 이 방식의 무선 CarPlay를 사용할 수 없습니다.
  끄는 동작이 내장 Wi-Fi를 활성화하거나 USB5V 전원을 차단하는 기능은 아닙니다.
- 별도 GRT 서비스가 만든 AP를 가져오는 방식은 이번에 구현하지 않았습니다.
  두 서비스가 같은 동글·AP를 동시에 제어하지 않도록 현재의 단일 관리 방식을 유지합니다.
- 원본 의존 파일을 가져와 준비하는 기존 경로는 바꾸지 않았습니다.
  별도 GRT 패키지를 추가로 설치해야 하는 새 요구 사항은 없습니다.
  원본 의존 프로젝트: https://github.com/GRT47/HKG_5W_USB_Wlan

기능별 반영 범위

01. 무선 CarPlay 연결
현재 패키지에 포함. Bluetooth/iAP2 연결과 외장 AP 정보 제공을 사용하며, 기존에 차량에서
동작한 연결 방식을 유지합니다. 다른 차종의 Wi-Fi 드라이버·설정으로 교체하지 않습니다.

02. 음악·안내·통화·Siri 오디오
현재 패키지에 포함. 사용자가 정상이라고 확인한 1.0.3 안내 음량 처리를 유지합니다.
한국판의 다른 오디오 코드를 덮어쓰지 않았습니다. 음악·통화·Siri를 일괄 안내 채널로 바꾸지 않습니다.

03. CarPlay 계기판·HUD 회전·거리·목적지 안내
현재 패키지에 포함. 기존 안내에 순정 형식 변환을 보강했습니다. ‘CarPlay 순정 형식 턴 표시’는
기본 켜짐입니다. 지원하는 의미·각도·거리 조건에서 변환하며 불명확하면 기존 표시를 유지합니다.

04. CarPlay 차선 모양과 권장 화살표
현재 패키지에 포함. 여러 방향이 있는 차선의 권장 표시를 화살표별로 보강하고 현재 안내와
차선 묶음의 연결을 확인합니다. 앱이 보내지 않은 권장 차선을 임의로 선택하지 않습니다.
앱별 데이터 차이 때문에 모든 도로의 차선 안내가 동일하게 제공되지는 않습니다.

05. 순정 내비와 휴대전화 차선 표시의 충돌
현재 패키지에 포함. 휴대전화 안내 중 순정 내비 차선 출력의 덮어쓰기를 제한하며,
늦은 이전 안내가 현재 휴대전화 안내를 지우는 경우를 줄입니다.

06. 유턴·회전교차로·갈림길·도착 표시
현재 패키지에 포함된 의미 변환을 보강했습니다. 휴대전화가 보낸 회전 종류·각도 등을 사용합니다.
‘전체 매핑 완료’ 또는 모든 특수 아이콘의 실차 표시를 확인했다고 안내하지 않습니다.
터널 등 앱이 별도 의미로 보내지 않는 정보는 전용 아이콘으로 확정할 수 없습니다.

07. AR HUD와 순정 거리 막대
지원되는 순정 안내 형식으로 데이터를 전달하는 기능을 추가했습니다.
별도 AR 화면을 생성하는 기능은 아닙니다. HUD 하드웨어·펌웨어·휴대전화 데이터에 따라
표시 결과가 달라지며 AR 애니메이션의 실제 지원 여부는 차량 시험으로 확인해야 합니다.
참고: https://github.com/VysseCodes/HMG-API/pull/75

08. Android Auto 계기판·HUD TBT
현재 패키지에 추가. 대상 차량의 선언과 패치 조건을 확인해 적용하며 이미 해당 순정 기능이
있는 구성은 유지합니다. Android Auto의 ‘순정 형식 턴 표시’는 별도 선택 기능으로 기본 꺼짐입니다.
외부 Wi-Fi 연결 자체의 정상 동작과 TBT 출력은 각각 확인해야 합니다.

09. Android Auto USB 메모리·허브 구분
현재 패키지에 추가. USB 메모리나 허브를 휴대전화로 오해해 유선 AA를 기다리는 경로를 좁게
제한합니다. 모든 USB 장치나 휴대전화의 유선 연결을 일괄 차단하지 않습니다.

10. Android Auto 외부 AP 자격 정보 제공
이번 설치본에서 제외. 기존 AP의 주소·주파수·접속 정보를 읽는 어댑터를 만들고 호스트 시험을
수행했으나, 대상 순정 파일의 추가 연결 지점을 모두 재확인하지 못해 별도 시험 소스로 보관합니다.
새 맵과 무선 AA 기능 플래그가 기존 CarPlay 설치에 영향을 주지 않도록 함께 분리했습니다.
이번 업데이트가 외장 동글 무선 AA를 새로 활성화하는 것은 아닙니다. 기존 AA TBT·USB 구분과
이 연결 어댑터는 별개이며, 별도의 AP·드라이버를 추가 실행하는 구성도 적용하지 않습니다.

11. 기기 설정·삭제·재등록
현재 패키지에 포함. 홈 폰 프로젝션 팝업과 무선 프로젝션 설정에서 브리지가 사용하는
순정 기기 연결 목록을 열도록 수정했습니다. 목록에서 삭제하면 Bluetooth 페어링도 함께
삭제됩니다. 자동 삭제는 하지 않습니다. NEMESIS 버튼을 교체한 기능은 아닙니다.

12. 한국판의 같은 종류 휴대전화 전환·삭제 지연
한국판의 별도 연결 관리자 구현을 확인했지만 전체를 복사하지 않았습니다.
현재 브리지와 연결·종료 소유 관계가 달라 별도 검증 없이 함께 설치하지 않습니다.
현재 순정 목록과 기존 브리지 정리 경로를 사용합니다.

13. 화면 멈춤 기록과 복구 요청
현재 패키지에 포함. 디코더 오류·시간 초과가 발생한 활성 무선 세션에서 기준 화면을 요청합니다.
한 번에 하나만 처리하고 최소 간격을 두며 주기적인 강제 요청은 하지 않습니다.
오류 신호 없이 발생한 모든 멈춤을 탐지·복구한다고 보장하지 않습니다.
참고: https://github.com/VysseCodes/HMG-API/pull/100

14. 종료 후 외부 AP 정지·복귀
현재 패키지에 포함. 실제 순정 논리 전원 OFF/ON 이벤트로 동작하며, 이전 OFF 상태를
일반 전원 조회나 늦은 이벤트가 덮어쓰지 못하게 했습니다. 기존 연결 설정을 보존합니다.
굿바이 애니메이션 자체나 USB 물리 전원을 제어하지 않습니다.

15. 지속적인 개발 로그와 USB 내보내기
현재 패키지에 포함. USB 없이 차량 내부에 이 패키지의 로그를 최대 8MiB 순환 저장합니다.
USB에는 허용한 상태·수치만 추출하며, 일반 로그 수집과 별도 코드 수집을 분리했습니다.
저장 공간 부족·긴 줄·갑작스러운 전원 차단으로 기록이 빠질 수 있습니다.

16. GPS·차속 전달 및 지도 지연
차량 GPS·차속을 전달하는 기존 경로를 확인했으며 기록 기능을 유지합니다.
한국판에서 별도 지연 개선은 확인하지 못했습니다. 차량 데이터의 통로가 있다는 사실만으로
폰이 언제나 차량 정보만 사용한다고 볼 수 없으며, 지도 지연을 해결했다고 표시하지 않습니다.

17. 외부 Wi-Fi 접속·핫스팟 공유·다른 주파수
이번 패키지는 검증된 5GHz 프로젝션 AP 구성을 유지합니다. 같은 동글의 외부 공유기 접속,
인터넷 공유 또는 2.4GHz 자동 전환을 새로 추가하지 않았습니다. 별도 기능·드라이버·동시 운용
검증이 필요하며 외부 동글 사용 스위치가 이를 활성화하지는 않습니다.

18. ADB·ADB 인증·NEMESIS 바로가기
HMG-API의 독립 선택 기능입니다. CarPlay 패키지가 자동으로 켜거나 새로 묶어 설치하지 않습니다.
USB ADB 장치 모드와 동글용 USB 호스트 모드는 같은 포트에서 동시에 사용할 수 없는 경우가 있습니다.
https://github.com/VysseCodes/HMG-API/tree/180185de2c57afb2cca4858d0be7828e8f1051d6/mods

19. HMG-API 엔진·부팅·서명·서비스·카탈로그·차량 맵
설치된 HMG-API core의 기능입니다. 이미 적용된 core 기능을 CarPlay 패키지에 중복 구현하지 않습니다.
지원되는 HMG-API를 설치해 사용하는 요구 조건은 유지합니다.

20. 차량 센서·배터리·EV 경로·배터리 컨디셔닝
일부는 HMG-API가 제공하는 API이고 일부는 별도 제안·통합 프로젝트입니다.
API가 존재한다고 완성된 사용자 기능이 자동으로 추가되는 것은 아닙니다. 이번 패키지에서
차량 배터리·충전·공조 설정을 임의로 제어하거나 제안 단계의 core 변경을 설치하지 않습니다.

21. 사이드 패널·버튼·예제 모드·다른 차량 지원
독립 기능 또는 개발 예제입니다. 다른 차량의 맵과 드라이버를 이 차량에 그대로 적용하지 않습니다.
예제 코드의 존재를 완성된 배포 기능으로 표시하지 않습니다.

직접 확인했다는 뜻은 아닙니다. 열린 PR은 병합된 정식 기능과 구별합니다.
