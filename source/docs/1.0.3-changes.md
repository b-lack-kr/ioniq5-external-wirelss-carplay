# 1.0.3 변경 사항

- 기기 연결 목록에 iPhone별 CarPlay 연결 버튼을 추가했습니다. 연결되지 않은 경우 순정 전화 연결 절차를 거쳐 CarPlay 연결을 요청합니다.
- 실제 연결된 기기를 기준으로 버튼 상태를 표시합니다.
- 순정 CarPlay 서비스와 iAP2, USB 동글이 준비 중일 때 제한시간 내 기다립니다.
- 같은 iPhone에 대한 미완료 Bluetooth/iAP 연결은 대기시간 이후 버튼으로 다시 시도할 수 있습니다. 실제 연결된 CarPlay는 유지합니다.
- 멈춘 동글 서비스는 버튼으로 재기동할 수 있습니다. 서비스가 실행 중이면 재시작하지 않으며 SSID와 암호를 재생성하지 않습니다.
- 수동 서비스 복구 때 차량의 현재 전원 ON이 확인된 뒤에만 동글을 활성화합니다.
- 추가 안내 기능의 초기화 실패가 CarPlay 연결 초기화를 막지 않도록 분리했습니다.
- 설치 및 USB 기록 수집에 HMG 후크 로딩 상태를 추가하고 연결 단계 기록을 보강했습니다.

기존 1.0.2를 제거한 후 새로 설치하거나, 1.0.3을 제거한 후 다시 설치할 수 있습니다. 동일한 1.0.3 USB를 다시 꽂으면 설치 대신 기록을 수집합니다.

ADB 1.0.3은 별도 패키지입니다. 이번 차량 시험용 USB에서 함께 설치하며, CarPlay 연결 전에도 Wi-Fi 접속 정보를 확인할 수 있습니다. 음소거 패키지는 별도입니다.

PC 검증과 실차 검증은 구분합니다. 이 설치본은 PC 검증 후 실차 확인을 위해 준비하며, 실차에서 확인한 CarPlay 설치본과 동일한 파일을 공개할 예정입니다.
