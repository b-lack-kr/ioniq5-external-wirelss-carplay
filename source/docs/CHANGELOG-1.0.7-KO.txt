IONIQ 5 USB 무선 CarPlay 1.0.7 — by blackr
2026-11-06 / 1.0.5에서 직접 업데이트 가능 / 실차 확인 전

1.0.6의 변경을 함께 포함
- timeout→screen_stopped 발생 후 활성 화면·Surface·소유권·세션이 유지될 때 한 번 재부착하는 복구.
- 앱 이탈·세션 변경·화면 소유권 변경 시 대기 중 복구 취소와 재부착 최소 간격 유지.
- 원시 미터가 없는 거리 갱신은 검증된 표시 거리/단위를 사용하고 출력 출처를 기록.
- 자세한 복구 조건과 네이티브 호출 취소 한계는 CHANGELOG-1.0.6-KO.txt 참고.

이번 1.0.7의 TBT 진행 입력
- 사용자 차량에서 가져온 정확한 Navi/API/service 코드를 대조했습니다.
- 기존 main TBT의10% 단위 진행값 외에 trap TBT에는 별도의 0..100 진행값이 있음을 확인했습니다.
- 이 세밀한 진행 입력과 유효한 0m 끝점 처리를 추가했습니다. 기존 457m 구간을 사용해 거리에서 진행률을 계산하며, 이 수식이 순정 native 수식과 같다고 주장하지 않습니다.
- 카메라·제한속도 등 같은 trap 정보의 다른 필드는 보존해야 하며, 해당 갱신 조건은 TBT-1.0.7-KO.txt에 정리합니다.
- 순정 native 엔진의 거리→진행률 수식, 증가/감소 방향, 회전 지점 통과 시 전이는 Java코드만으로 확정되지 않습니다.
  차량에 값을 보낸다는 것과 계기판/HUD의 커서 이동을 실제로 확인했다는 것은 구분합니다.
  순정과 같은 회전 통과 애니메이션을 실차에서 검증 완료한 버전이라고 표시하지 않습니다.

설치 및 로그
- 1.0.5에서 1.0.6을 거치지 않고 바로 1.0.7로 업데이트할 수 있습니다. 기존 연결 설정을 유지합니다.
- 정확히 서명된 1.0.6 설치본에서의 업데이트와 복구도 지원합니다.
- NEMESIS Uninstall 완료 후 신규 설치 가능. 이전 인증된 작업 기록은 보관합니다.
- 같은 1.0.7이 정상 설치된 후 동일 USB에 Yes를 누르면 재설치하지 않고 로그만 수집합니다.
- 새 설치·업데이트 실패 시 실제 원인을 기록하며, 로그 수집 실패를 이유로 재설치하지 않습니다.
- HMG-API 1.0.1 이상, 음소거·시작 동의 4.3.2는 별개 패키지입니다.

유지·미확인 범위
정상 확인된 안내 음량과 동글 드라이버/AP 구동, 전원 OFF/ON 이벤트 처리를 유지합니다.
GPS/차속 전체 표시 지연, 모든 터널/AR 표현, 오류 신호 없는 화면 멈춤, USB 5V 물리 차단은
이번 버전에서 실차 해결 완료를 주장하는 항목이 아닙니다.
