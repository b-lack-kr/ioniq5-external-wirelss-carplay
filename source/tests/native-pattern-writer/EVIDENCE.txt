NativePatternWriter host contract and native clear evidence

The actual production writer is compiled with Java8 and only dedicated minimal
Context, Points, CpTurns.PatternSink, and Dipo logging fixtures. No HMG-API v2,
Cluster class, NavigationCluster class, or new convenience API is supplied.
Points method lookup is the mapped framework.navigation_cluster.update_clu_data_new_14;
the receiver comes from framework.navigation_cluster.new with the original Context.
The writer validates five primitive-int parameters, void return, instance method,
and receiver assignability before making any write. Missing/wrong mappings return
null and leave ordinary projection free to continue without a pattern sink.

Tests exercise exact tuple order, unsigned payload bounds, rejected arity/types,
wrong receivers, missing API/linkage/constructor errors, inaccessible methods,
target exceptions and retry, one failure log per failure streak, reset on success,
and recorder exceptions. Logging is isolated so it cannot break null/false fallback.
