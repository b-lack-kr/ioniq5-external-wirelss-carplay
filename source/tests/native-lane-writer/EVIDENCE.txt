The adapter improves observability over HMG-API 1.0.2 Cluster.laneInfo, whose
generic call wrapper catches all Throwable and always returns void: missing
mapping, bad receiver/signature, linkage failure and invocation exceptions now
return false. Resolution is lazy on the independent auxiliary output worker and
retried on the next real input event; no timer and no core TBT constructor IPC.

True means only a normally returned framework invocation. It cannot prove
Binder transport success, MCU acknowledgement or physical HUD/cluster rendering,
because the exact framework API itself suppresses RemoteException. No private
mService field or raw Binder transaction is used to overstate this guarantee.

Host tests cover valid/clear frame preservation, clone isolation, invalid frame
rejection, optional map/receiver/signature failures, same-input retry, and a
NoClassDefFoundError thrown by the reflected receiver.
