Reference HKMC_Navi_ExSL com/mnsoft/navi/d/f.java jR() loads the G40/G45
paths selected by b/i.fj(), d/b.bT() (map_index0/1 chooses navi/navi2).
jS() loads the exact data/BIN code files; both use system library fallback.
These exact code-file exceptions do not authorize other content below data
or storage. The collector never opens map_index.cfg or map/user files.

The collector asks ActivityManager for the exact com.mnsoft.navi process.
For that PID alone it checks /proc/PID/cmdline (256-byte bound) and maps
(1MiB bound), retaining ONLY matches to the two allowlisted library paths.
Raw proc contents, process identities and memory addresses are never exported.
One unique loaded path is preferred and labeled ACTIVE_PROCESS_MAP. If no
unique allowed loaded path is available, fixed fallback selection is labeled
FIXED_FALLBACK_UNCONFIRMED. This does not claim the selected file was loaded.

All copied sources must be regular canonical files, satisfy their size cap
and format header (ARM32 little-endian ELF, ODEX035/036, or APK ZIP magic).
Copying stops at the stat size, rejects growth/truncation/changed stat, syncs
the file, then publishes a completed destination. Partial outputs are removed.
Neither output directories/files nor source symlinks are overwritten/followed.
Missing, changed, oversized, unsafe or unreadable files yield explicit status
and overall partial7 without changing installed CarPlay state.

Persistent log evidence:
Official HMG-API1.0.1 core/runtime/java/hmgapi/engine/LogKeeper.java and
ModRuntime.LOG_SERVICE establish an always-on logcat HMG-API keeper at
/data/hmgapi/logs/hmgapi/log.log with256KiB rotation to .1. The collector now
exports current and previous files separately through the existing strict
History sanitizer, maximum256 reconstructed events per source and192KiB
input tail each. Volatile logcat is still separately collected. This recovers
previous-boot observations while retained, but is bounded rotating history
and is not a guarantee of every past event. Other mod logs and raw text are
discarded. No new logger or vehicle process is started.
