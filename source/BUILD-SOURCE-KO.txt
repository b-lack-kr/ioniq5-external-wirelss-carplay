준비물
Python 3.9+, JDK17, Android SDK Platform34 android.jar, D8/R8 JAR, sh.
Android target은 API19 / Dalvik035입니다. 설치된 HMG-API1.0.1 이상의 runtime을 사용하며 전체 runtime을 교체하지 않습니다.

빌드 명령
python3 tools/rebuild_usb.py --java-home /path/to/jdk17 --android-jar /path/to/android.jar --d8 /path/to/r8.jar --out /path/to/empty-output --sign-key /path/outside-source/author.key

새 저자 키가 필요하면 --generate-key를 추가합니다. 기존 키를 덮어쓰지 않습니다. 서명 키와 출력 폴더는 소스 트리 밖에 두세요. 서명자를 바꾸면 기존 by blackr 설치본을 덮어쓸 권한이 생기지 않으며 새 서명에 맞는 신규 설치 대상으로 사용해야 합니다.

출력

CarPlay ZIP에는 음소거 패키지가 포함되지 않고 설치 여부도 요구하지 않습니다.
USB ZIP 전체 내용을 루트에 풉니다. Wi-Fi 드라이버와 helper 입력은 docs/EXTERNAL-INPUTS-KO.txt를 따릅니다. 공개 ZIP은 타인의 드라이버·제조사 APK·순정 라이브러리를 내장하지 않습니다. 이미 인증된 외부 동글 자산이 설치된 차량은 이를 유지합니다.

설치와 기록
- 처음 설치하는 차량: NEMESIS 자동 실행에 동의하면 설치합니다.
- 기존 공개 1.0.2 등 이전 패키지 사용자는 NEMESIS에서 CarPlay 패키지를 Uninstall한 뒤 설치하세요. NEMESIS와 HMG-API는 유지합니다.
- 동일한 정확한 버전: 재설치하지 않고 USB에 기록을 수집합니다.
- 제거된 이전 설치 기록은 검증 후 보관하며, 설치가 완료된 동일한 공개 1.0.3은 재설치하지 않고 로그를 수집합니다.
- Uninstall 후 설치도 이전 기록을 검증·보관한 뒤 신규 트랜잭션을 생성합니다.
- 설치 후 재부팅이 필요합니다. AA Java 디코더와 새 메모리 레시피를 이전 GPM 프로세스와 혼용하지 않습니다.
- 음소거 및 startup4.3.2는 각각 별도 설치·삭제합니다.

기능 한계
기본 TBT는 사용자 정상 기준1.0.9의 정책을 유지하고 추천 차선/정션뷰는 별도 입력·출력 작업자로 보강합니다. 1.0.9에서 두 기능이 동작한 것은 아닙니다. CP 원시 메시지 관찰은 bounded async 방식이며 기존 동기식 파서·주기적 화면 재전송·별도 차선 거리 호출을 복귀시키지 않습니다.
공개 설정은 AR 표시(기본 OFF, CP/AA 공통)와 외부 동글 사용(기본 ON)입니다. 기본 TBT·추천 차선·지원되는 CarPlay 정션뷰는 AR OFF에서도 처리합니다. 일반 회전 AR은 CP/AA 공통300m 기준이며 고속도로·정션 그림의 별도 조건은 유지합니다. 순정 커서도 고정된다는 사용자 확인에 따라 별도 통과 애니메이션을 추가하지 않습니다. docs/AR-STOCK-EVIDENCE-1.0.15.txt를 확인하세요.
차량 검증 전입니다. 추천/우선 차선은 휴대폰이 실제로 전달한 유효 정보를 사용합니다. 차선 수만으로 범용 정션 그림을 선택하는 기능은 중단했습니다. 물리 USB5V 차단, 모든 교차로 형상은 지원 완료 항목이 아닙니다. GPS 좌표·시각·방향은 유지하고, 요청된 무선 CarPlay RMC 속도 필드는 실제 차량 콜백 값으로 맞춥니다. docs/RMC-VEHICLE-SPEED-1.0.15.txt를 확인하세요.
