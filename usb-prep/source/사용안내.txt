IONIQ 5 USB 무선 CarPlay 1.0.1 · by blackr
음소거 일시정지·해제 시 재생 1.1.0 포함

대상: 한국 NEEV 260902 / tcc803x, NEMESIS, HMG-API 1.0.1과 활성화된 Hooks, 지원하는 5GHz USB Wi-Fi 동글.
기준 차량은 2023MY IONIQ5이며 Archer T3U Nano로 사용자가 설치·동작을 확인했습니다. 다른 차종/펌웨어는 이 패키지 대상이 아닙니다.

USB 준비
1. 운영체제에 맞는 준비 도구 ZIP을 PC에 풉니다. USB 내용을 먼저 백업하세요.
2. Mac은 USB-준비-macOS.command를 실행하고, Windows는 Prepare-USB-Windows.cmd를 관리자 권한으로 실행합니다.
3. 표시된 드라이브의 이름과 용량을 확인하여 USB 볼륨을 선택합니다. 확인 문구를 직접 입력하면 선택한 볼륨의 기존 파일·폴더를 삭제하고 설치 파일을 넣습니다. 파티션 생성·포맷을 하지 않으며 파일시스템과 볼륨 이름을 유지합니다. 볼륨이 여러 개면 선택한 볼륨만 정리합니다.
4. 31개 파일 검증을 마치면 안전하게 추출합니다. 차량에서는 인터넷 연결이 필요 없습니다.

FAT32 또는 exFAT로 이미 사용 중인 USB 볼륨을 선택하세요. 지원하지 않는 파일시스템은 도구가 변환하지 않습니다. 다운로드와 준비 파일 검증을 마친 뒤 USB 내용을 삭제하며, 숨김 파일과 이전 설치 기록도 삭제되므로 먼저 백업하세요.

운영체제 관리 폴더 예외: Mac은 USB 최상위의 .Spotlight-V100, .fseventsd, .Trashes를, Windows는 System Volume Information을 남깁니다. 해당 폴더의 접근 권한을 강제로 변경하지 않습니다. 그 밖의 기존 파일·폴더를 지우지 못하면 설치 준비를 중단합니다.

PC에 파일만 만들려면 Mac에서 /bin/sh USB-준비-macOS.command --prepare-only 실행.
Windows에서는 powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Prepare-USB.ps1 -PrepareOnly 실행.
USB_READY 안의 5개 항목을 빈 USB 최상위에 복사합니다. 같은 폴더에 있는 차량용 ZIP을 사용할 수 있으며, 없으면 공식 릴리스에서 받습니다. 동글 파일은 GRT47 v2.0.2 원본을 공식 GitHub에서 받고 해시를 확인합니다.

2026-11-05 준비 도구 수정: 버전은 1.0.1을 유지합니다. 이전에 받은 준비 도구 ZIP은 다시 다운로드하세요. 차량용 CarPlay·음소거 설치 파일은 변경하지 않았습니다.

기존 설치
CarPlay1.0.0이 설치돼 있으면 CarPlay 패키지를 Uninstall하고 HMG-API에 남은 Apply changes를 적용한 뒤 내비를 재부팅하세요. NEMESIS와 HMG-API 자체는 유지합니다.
CarPlay1.0.1이 이미 설치돼 있으면 삭제할 필요 없습니다. 음소거1.0.0은 이번 통합판이1.1.0으로 업데이트합니다. 동일한 음소거1.1.0은 그대로 유지하며 꺼짐 설정도 유지합니다.
이전 CarPlay0.1.10/0.1.11에서 직접 업데이트할 때는 기존 Wi-Fi 이름과 암호를 유지합니다. 삭제 후 신규 설치도 지원합니다.

설치와 사용
1. 주차 상태에서 내비 부팅 후 USB를 데이터 포트에 꽂고 NEMESIS 확인창에서 Yes를 누릅니다.
2. Operation completed successfully와 최종 설치 완료를 기다립니다.
3. USB를5GHz 동글로 바꾸고 내비를 재부팅합니다. 정상 부팅·동글 시작·연결 대기 팝업은 표시하지 않습니다.
4. 아이폰에서 Bluetooth와 Wi-Fi를 켜고 차량 폰 프로젝션에서 CarPlay를 연결합니다.
신규 설치는 Hyundai_숫자6자리 이름과 암호를 새로 만듭니다. 이전 등록으로 연결되지 않으면 아이폰의 기존 CarPlay·차량 Bluetooth 등록을 지우고 다시 등록합니다. Wi-Fi 암호를 수동 입력할 필요는 없습니다.

음소거
재생 중 음소거하면 일시정지하며, 버튼이나 볼륨 조절로 실제 음소거가 해제되면 재생합니다. 원래 일시정지 상태였던 곡은 자동 재생하지 않습니다. CarPlay 연결 교체, 확인된 수동 미디어 입력이나 통화/Siri 조건에서는 재생 예약을 취소합니다.

기록과 복구
설치 결과는 USB의 NEEV_CP_RESULT_* 및 NEEV_BUNDLE_RESULT_*의 STATUS.txt에 남습니다. 설치 완료 후 같은 USB로 다시 실행하면 최근 AP/CarPlay/부팅 서비스 기록을 가져옵니다. 기록이 일부 없으면 LOGS_EXPORTED_PARTIAL일 수 있습니다.
CarPlay 복구는 USB 루트에 NEEV-CP-RESTORE라는 빈 파일을 만든 후 실행하고 재부팅합니다. 이 복구는 독립된 음소거 모드를 제거하지 않습니다. 복구 후 재설치하려면 해당 빈 파일을 지우세요.
음소거만 제거하려면 NEMESIS My Packages의 IONIQ5 CarPlay Mute Pause를 Uninstall하고 재부팅합니다.
