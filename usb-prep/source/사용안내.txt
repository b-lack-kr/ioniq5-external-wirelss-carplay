IONIQ 5 USB 무선 CarPlay 1.0.3 · by blackr

대상: 한국 NEEV 260902 / tcc803x, NEMESIS, HMG-API 1.0.1 이상과 활성화된 Hooks, 지원하는 5GHz USB Wi-Fi 동글.
기준 차량은 2023MY IONIQ5이며 Archer T3U Nano를 사용했습니다. 다른 차종/펌웨어는 이 패키지 대상이 아닙니다.
이 설치본은 CarPlay만 설치합니다. 음소거 일시정지 패키지는 필수 의존성이 아니며 따로 설치할 수 있습니다.

USB 준비
1. 운영체제에 맞는 준비 도구 ZIP을 PC 내장 저장 공간에 풉니다. USB 내용을 먼저 백업하세요.
2. Mac은 USB-준비-macOS.command를 실행하고, Windows는 Prepare-USB-Windows.cmd를 관리자 권한으로 실행합니다.
3. 표시된 드라이브의 이름과 용량을 확인하여 USB 볼륨을 선택합니다. 확인 문구를 직접 입력하면 선택한 볼륨의 기존 파일·폴더를 삭제하고 설치 파일을 넣습니다.
4. 파일 검증 완료 후 안전하게 추출합니다. 차량에서는 인터넷 연결이 필요 없습니다.

파티션 생성·포맷을 하지 않으며 파일시스템과 볼륨 이름을 유지합니다. 볼륨이 여러 개면 선택한 볼륨만 정리합니다. FAT32 또는 exFAT로 이미 사용 중인 USB를 선택하세요. 지원하지 않는 파일시스템은 도구가 변환하지 않습니다.
다운로드와 준비 파일 검증을 마친 뒤 USB 내용을 삭제합니다. 숨김 파일과 이전 설치 기록도 삭제되므로 먼저 백업하세요.
운영체제 관리 폴더 예외: Mac은 USB 최상위의 .Spotlight-V100, .fseventsd, .Trashes를, Windows는 System Volume Information을 남깁니다. 해당 폴더의 접근 권한을 강제로 변경하지 않습니다. 그 밖의 기존 파일·폴더를 지우지 못하면 설치 준비를 중단합니다.
Mac의 USB 목록 인식·exFAT 보조 파일 처리와 Windows 볼륨 GUID 경로 수정이 포함되어 있습니다. 준비 완료 시 검증한 실제 파일 수를 표시합니다.

PC에 파일만 만들기
Mac: /bin/sh USB-준비-macOS.command --prepare-only
Windows: powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Prepare-USB.ps1 -PrepareOnly
USB_READY 안의 모든 항목을 USB 최상위에 복사합니다. 같은 폴더에 있는 차량용 ZIP을 사용할 수 있으며, 없으면 공식 릴리스에서 받습니다. 동글 파일은 GRT47 v2.0.2 원본을 공식 GitHub에서 받고 SHA-256을 확인합니다.

기존 설치
이전 CarPlay 패키지가 설치되어 있다면 NEMESIS의 My Packages에서 해당 CarPlay 패키지를 Uninstall한 뒤 설치하세요. NEMESIS와 HMG-API는 유지합니다.
CarPlay가 설치되지 않은 차량은 신규 설치합니다. NEMESIS와 HMG-API 자체를 삭제할 필요는 없습니다.
이미 설치된 별도 음소거 패키지는 이 설치본이 설치·업데이트·제거하지 않습니다.
같은 1.0.3 설치를 완료한 뒤 같은 USB를 다시 실행하면 재설치 대신 로그를 수집합니다.

설치와 사용
1. 차량의 기기 연결 설정에서 기존 휴대전화 등록을 삭제합니다. 아이폰의 설정 → Bluetooth → 차량 옆 정보 버튼 → 이 기기 지우기, 설정 → 일반 → CarPlay → 기존 차량 → 이 자동차 지우기도 진행합니다.
2. 주차 상태에서 내비 부팅 후 USB를 데이터 포트에 꽂고 NEMESIS 확인창에서 Yes를 누릅니다.
3. Operation completed successfully와 최종 설치 완료를 기다립니다.
4. USB를 5GHz 동글로 바꾸고 내비를 재부팅합니다. 정상 부팅·동글 시작·연결 대기 팝업은 표시하지 않습니다.
5. 아이폰에서 Bluetooth와 Wi-Fi를 켜고 차량 Bluetooth를 새로 등록합니다. CarPlay 연결 확인창에서 연결을 선택합니다.
연결 확인창이 나타나지 않으면 기기 연결 설정의 CarPlay 버튼으로 연결을 다시 시도할 수 있습니다.
신규 설치는 Hyundai_숫자6자리 이름과 암호를 새로 만듭니다. Wi-Fi 암호를 수동 입력할 필요는 없습니다. 이전 등록으로 연결되지 않으면 차량과 아이폰의 CarPlay 등록 상태를 확인한 뒤 다시 등록하세요.

기록과 복구
설치 결과는 USB의 NEEV_CP_RESULT_* 및 NEEV_BUNDLE_RESULT_*의 STATUS.txt에 남습니다. 설치 완료 후 같은 USB로 다시 실행하면 최근 AP/CarPlay/부팅 서비스 기록을 가져옵니다. 기록이 일부 없으면 LOGS_EXPORTED_PARTIAL일 수 있습니다.
CarPlay 복구는 USB 루트에 NEEV-CP-RESTORE라는 빈 파일을 만든 후 실행하고 재부팅합니다. 이 복구는 독립된 음소거 모드를 제거하지 않습니다. 복구 후 재설치하려면 해당 빈 파일을 지우세요.
