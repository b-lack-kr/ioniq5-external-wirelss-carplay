# HMG-API 연결 지점 진단

CarPlay 1.1.4 시험본 또는 CarPlay Heading Diagnostic 0.2.0에 `isn't one HMG-API has` 오류가 나타날 때 사용하는 **읽기 전용 진단 도구**입니다. 1.1.4는 현재 실차 시험본이며, 이 도구는 오류를 자동으로 수정하거나 설치된 맵을 변경하지 않습니다.

빈 USB의 최상위에 이 폴더의 `NEMESIS.data`와 `NEMESIS.sh`를 넣고 차량에 연결한 뒤 실행을 확인하면 `HMG_MAP_DIAG_...` 폴더가 생성됩니다. 결과에는 설치된 패키지 및 모드 이름, 차량 빌드와 연결 지점 맵, 관련 서비스 상태와 오류 로그가 포함됩니다. 결과를 공유하기 전에 내용을 확인하세요.

`reference-dipo-points.json`은 해당 차량용 1.1.4 시험본에 포함됐던 두 연결 지점과 상위 클래스 정의를 기록한 참고 자료입니다. 차량에서 선택된 맵과 일치하는지, 차량 빌드 및 기존 맵이 호환되는지 확인하기 전에는 덮어쓰지 마세요. 맵 반영 후 실제 로드 여부는 재시작 후 확인해야 합니다.
